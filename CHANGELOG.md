- Tests : SearchApostrophe1367Tests. Verify.ps1 (agent) : 2569/2569, 0 avertissement, 0 erreur ; DLL 0.1367.0.0. Non validé en jeu.
### English
- Searches and apostrophes (test T-0.1354-1): probe of the game's sheets (items, places, NPCs, monsters, quests, FATEs, duties, mounts, minions, leves, statuses, actions, achievements, titles, key items; French and English): names use the straight apostrophe only, as Tensho's texts do (D-162). Evidence docs/evidence/0.1367-search-apostrophes.md; test SearchApostrophe1367Tests (real names Item#8090 and #8568, and no search place without the shared helper).

## 0.1366.0
- Plan global, X-387 : Liens de carte du chat, second essai (X-365 pas réussi en jeu le 15/11). Clic gauche : le lien visait une autre zone que celle du joueur (Thanalan occidental, carte 20, la carte Tensho restait sur la zone du joueur) ; la carte Tensho, quand elle est ouverte, va maintenant sur la carte du lien cliqué, où elle montre le drapeau du jeu. Clic droit : le clic est lu depuis Windows (bouton pressé, jeu au premier plan, aucune fenêtre Tensho sous la souris) au lieu de l'état de clic d'ImGui, et une ligne de journal en mode développeur le dit à chaque clic (« Chat link right click », « Chat link clicked »). X-395 mineur 4 : un lien survolé dont la sortie n'est pas venue n'est gardé que 60 s et tant que le curseur reste à moins de 48 pixels (un clic droit dans le monde plus tard n'ouvre plus le menu). X-395 mineur 3 : une plantation efface le menu de carreau noté, et un menu fermé sans rien faire est oublié après 4 s au lieu de 10 s. Tests ChatLinkGarden1366Tests ; ChatLinkMenu1351Tests suit les nouvelles signatures.
- Pour les joueurs : liens de carte du chat : la carte Tensho suit un lien cliqué jusqu'à sa zone, et le clic droit sur un lien de carte ouvre le menu de lieu de Tensho de façon plus sûre.
- Tests : ChatLinkGarden1366Tests. Verify.ps1 (agent) : 2566/2566, 0 avertissement, 0 erreur ; DLL 0.1366.0.0. Non validé en jeu.
### English
- Chat map links, second try (X-365 failed in game on 15/11). Left click: the link pointed at another zone than the player's (Western Thanalan, map 20; the Tensho map stayed on the player's zone); the Tensho map, when it is open, now goes to the clicked link's map, where it shows the game's flag. Right click: the click is read from Windows (button pressed, game in front, no Tensho window under the mouse) instead of ImGui's click state, and a developer-mode log line says so at each click (« Chat link right click », « Chat link clicked »). X-395 minor 4: a hovered link whose mouse-out never came is kept only 60 s and while the cursor stays within 48 pixels (a later right click in the world no longer opens the menu). X-395 minor 3: a planting clears the noted bed menu, and a menu closed without action is forgotten after 4 s instead of 10 s. Tests ChatLinkGarden1366Tests; ChatLinkMenu1351Tests follows the new signatures.
- For players: Chat map links: the Tensho map follows a clicked link to its zone, and right-clicking a map link opens Tensho's place menu more reliably.

## 0.1651.0
- Plan global, X-675 : Fenêtre de chat (X-675, signalé par l'utilisateur le 20/11 avec deux captures) : la fenêtre « Choisir du texte » du clic droit rapetissait à chaque image jusqu'à ce que sa zone de texte disparaisse. Cause : une fenêtre surgissante d'ImGui prend toujours la taille de son contenu, et la zone de texte prenait la place restante (-1,-1) : chacune réduisait l'autre. La zone a maintenant une taille fixe tirée de la fenêtre du chat (ChatCopy.SelectBox : aussi large que la fenêtre, 320 au moins ; aussi haute, de 200 à 600, moins la ligne d'aide, le bouton et les marges ; jamais sous 240 × 120) ; la fenêtre surgissante se règle autour d'elle.
- Pour les joueurs : fenêtre de chat : la fenêtre « Choisir du texte » garde sa taille au lieu de rapetisser jusqu'à disparaître.
- Tests : ChatSelectBox1651Tests. Verify.ps1 (agent) : 3446/3446, 0 avertissement, 0 erreur ; DLL 0.1651.0.0. Non validé en jeu.
### English
- Chat window (X-675, reported by the user on 20/11 with two screenshots): the right-click « Select text » popup shrank each frame until its text box was gone. Cause: an ImGui popup always takes its content's size, and the text box took the space left (-1,-1): each shrank the other. The box now has a fixed size taken from the chat window (ChatCopy.SelectBox: as wide as the window, 320 at least; as high, 200 to 600, less the help line, the button and the margins; never under 240 × 120); the popup fits around it.
- For players: Chat window: the « Select text » box keeps its size instead of shrinking until it disappears.

## 0.1650.0

- Tests : ChatPriority1650Tests. Verify.ps1 (agent) : 3443/3443, 0 avertissement, 0 erreur ; DLL 0.1650.0.0. Non validé en jeu.
### English
- Chat window (X-564), a measured attempt: the chat part of the JIT warm-up (the window's first frame, about 730 methods) is compiled at normal priority; the rest of the warm-up goes back below normal, as before (X-433). Measures before (log of 20/11, loads made while a build ran beside the game): chat part ready 4.7 to 7.9 s after the load, lines drawn 3.5 to 9.7 s after it, and a compilation of 704 ms with 109 ms of processor: the thread waited for the processor. Evidence in docs/evidence/0.1650-chat-part-priority.md. The point stays open until the lines are drawn within 3 s.
- For players: Chat window: its lines come sooner after the plugin loads.

## 0.1645.0
- Plan global, X-672 : Tests (X-672) : le test A14 du journal des gils (« After error 1551 ») a échoué une fois en CI sur la 0.1640 (« written again after the change of character »), vert ensuite, sur une machine si chargée que douze tests y ont pris 499 s d'une suite de 195 s. Ses seules attentes bornées : la fin de l'écriture en arrière-plan attendue 5 s au plus, alors que ces écritures tournent sur le pool de fils, qu'une machine chargée démarre plusieurs secondes en retard, et un verrou attendu 5 s. Toutes les attentes de ces tests (A03, A14, A16) attendent maintenant leur signal (file d'écriture vide, échange fini) avec une garde de 2 min qui n'arrête qu'un test vraiment bloqué ; un test garde le fichier sans borne de quelques secondes.
- Tests : FlakyGil1645Tests. Verify.ps1 (agent) : 3430/3430, 0 avertissement, 0 erreur ; DLL 0.1645.0.0. Rien à essayer en jeu.
### English
- Tests (X-672): the A14 test of the gil journal (« After error 1551 ») failed once in CI on 0.1640 (« written again after the change of character »), green afterwards, on a machine so loaded that twelve tests took 499 s of a 195 s run. Its only bounded waits: the background write's end waited 5 s at most, while those writes run on the thread pool, which a loaded machine starts seconds late, and a gate waited 5 s. Every wait of these tests (A03, A14, A16) now waits on its signal (write queue empty, exchange over) with a guard of 2 min that only stops a test really stuck; a test keeps the file free of bounds of a few seconds.

## 0.1644.0
- Plan global, X-673 : Relecture du bloc 0.1639 à 0.1643, constats mineurs. M1 : quand l'historique du chat est relu après qu'un message a été épinglé, chaque ligne reçoit un nouveau numéro ; l'épingle gardait l'ancien, si bien qu'un clic remontait en haut de l'onglet au lieu d'aller au message, et que le menu du message proposait de l'épingler une deuxième fois sans offrir « Désépingler ». L'épingle suit maintenant son message (nouveau numéro) ; une épingle dont la ligne était déjà sortie de la mémoire garde le sien. M2 : dans le lanceur des tests, un fil laissé derrière un test bloqué (X-671) reprenait des classes quand ce test finissait par revenir, sans surveillance, parfois en même temps que les classes « seules », et ses résultats étaient relevés à moitié avec un message trompeur ; un fil laissé derrière ne commence plus rien (décidé sous le même verrou que le début d'un test), et le lanceur donne un signal à chaque fil laissé, pour que les tests l'attendent sans délai. M3 : une ligne de ce journal (0.1639) nommait un fichier et un dossier de l'agent ; réécrite, et le contrôle qui ne l'avait pas vue est corrigé.
- Pour les joueurs : fenêtre de chat : un message épinglé va toujours à sa ligne, et se désépingle depuis son menu, après la relecture de l'historique.
- Tests : ChatPinRestore1644Tests, RunnerLeft1644Tests. Verify.ps1 (agent) : 3429/3429, 0 avertissement, 0 erreur ; DLL 0.1644.0.0. Non validé en jeu.
### English
- Review of block 0.1639 to 0.1643, minor findings. M1: when the chat history is read back after a message was pinned, every line gets a new number; the pin kept the old one, so a click went to the top of the tab instead of the message, and the message's menu offered to pin it a second time without « Unpin ». The pin now follows its message (new number); a pin whose line had already left memory keeps its own. M2: in the test runner, a thread left behind on a hung test (X-671) took more classes once that test came back, unwatched, sometimes beside the « alone » classes, and its results were read half way with a misleading message; a thread left behind now begins nothing more (decided under the same lock as a test's start), and the runner gives a signal for each thread left, so the tests wait on it, never on a delay. M3: a line of this changelog (0.1639) named an agent file and folder; rewritten, and the check that missed it is fixed.
- For players: Chat window: a pinned message still goes to its line, and can be unpinned from its menu, after the history is read back.

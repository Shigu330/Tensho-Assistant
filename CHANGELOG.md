## 0.1473.0
- Plan global, X-491 : Confidentialité (relecture 0.1472, I1 ; R04, R25) : le nom et le monde d'un joueur réel, et le début de son message, étaient écrits dans un commentaire du code (0.1471), dans le commentaire d'un test, dans le CHANGELOG et dans le texte du plan (X-472) ; le nom de personnage de l'utilisateur était 49 fois dans un ancien journal de preuve (0.160). Ils sont remplacés par « Name [world icon] World », « THE EXAMPLE » et « Joueur ». Garde-fou : le test PrivateNames1473Tests lit chaque fichier suivi (ou ajouté) et refuse tout nom d'une liste gardée hors du dépôt (son chemin donné par la variable TENSHO_PRIVATE_NAMES ; sans elle, comme dans la CI, la liste n'est pas lue ; donnée mais absente : échec) ; un échec nomme le fichier, la ligne et le numéro de l'entrée, jamais le nom. Les outils du mainteneur refusent un tel nom avant d'écrire un texte public. L'historique git n'est pas réécrit (décision de l'utilisateur). Avec lui, X-489 (produire à nouveau le plan dépassait son budget : 300 015 octets pour 300 000) : les points faits ont leur page, produite avec le plan global (docs/project/GLOBAL-PLAN-DONE.md, deux langues, budget de 400 Ko) ; GLOBAL-PLAN garde les points ouverts entiers et, sous chaque tableau, le nombre de ses points faits avec le lien vers leur section (214 758 octets) ; il ne grandit plus qu'avec les points ouverts. Test PlanCompact1092Tests (les deux pages et leurs budgets).
- Tests : PrivateNames1473Tests, PlanCompact1092Tests. Verify.ps1 (agent) : 2877/2877, 0 avertissement, 0 erreur ; DLL 0.1473.0.0. Rien à essayer en jeu.
### English
- Privacy (review of 0.1472, I1; R04, R25): a real player's name and world, and the start of their message, were written in a comment of the code (0.1471), in a test's comment, in the CHANGELOG and in the plan's text (X-472); the user's own character name was in an old evidence log 49 times (0.160). With it, X-489 (producing the plan again went over its budget: 300,015 bytes for 300,000): the done points have their page, produced with the global plan (docs/project/GLOBAL-PLAN-DONE.md, both languages, a 400 KB budget); GLOBAL-PLAN keeps the open points whole and, under each table, the count of its done points with the link to their section (214,758 bytes); it grows with the open points only. ## 0.1469.0
- Plan global, X-480 : Carte, couches d'un territoire (relecture 0.1467 I2) : la sonde PROBE_FLOORS=check (ShopCurrencyProbe, qui compile le MapFloors.cs du plugin) a vérifié la règle de 0.1464 sur tous les territoires dont planmap.lgb nomme deux cartes ou plus : 316 (et non 62), dont 131 à disposition partagée et 204 avec une carte d'un autre cadre ; sur 4430 PNJ de la feuille Level, 295 étaient mis sur une carte qui n'est pas la leur et 4 sur aucune. Preuve docs/evidence/0.1469-map-floors-check.md. Mineur M5 de la relecture : les trois chargeurs (marchands, joueurs de Triple Triade, sonnettes et coffres) font la même chose, les étages lus une fois par disposition et carte (MapFloorReader.FloorCache) ; caches refaits (floors-1469).
- Pour les joueurs : carte : les marchands, joueurs de Triple Triade, sonnettes et coffres des lieux dessinés sur plusieurs cartes s'affichent de nouveau sur la bonne carte ; certains manquaient ou apparaissaient sur une autre carte.
- Tests : MapFloors1469Tests. Verify.ps1 (agent) : 2862/2862, 0 avertissement, 0 erreur ; DLL 0.1469.0.0. Non validé en jeu.
### English
- Map, floors of a territory (review of 0.1467 I2): the probe PROBE_FLOORS=check (ShopCurrencyProbe, which compiles the plugin's MapFloors.cs) checked 0.1464's rule on every territory whose planmap.lgb names two maps or more: 316 (not 62), 131 of them with a shared layout and 204 with a map of another frame; of 4430 Level NPCs, 295 were put on a map that is not theirs and 4 on none. Now (MapFloors.Floors) a box counts only when its map is the territory's or another floor of its frame (same territory, scale and offset, its own marker range); a placement in no box stays on the territory's map, never left out. On the same 4430 NPCs: none on a map that is not theirs (4117 on their own, 275 of them on a floor; 313 on the territory's map, as before 0.1464); floors in 78 territories. Evidence docs/evidence/0.1469-map-floors-check.md. - For players: Map: vendors, Triple Triad players, summoning bells and chests of places drawn on several maps show on the right map again; some were missing or shown on another map.

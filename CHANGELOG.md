## 0.1617.0
- Plan global, X-455 : Fenêtre de chat, options d'un chat ordinaire choisies par l'utilisateur le 15/11 (X-455 E2, E3, E4, E7). - Tests : ChatCopy1617Tests. Verify.ps1 (agent) : 3345/3345, 0 avertissement, 0 erreur ; DLL 0.1617.0.0. Non validé en jeu.
### English
- Chat window, the options of an ordinary chat chosen by the user on 15/11 (X-455 E2, E3, E4, E7). E2: with the window in front, Ctrl+A chooses the whole tab (a band shows it; Esc or a click lets it go) and Ctrl+C copies it, or else the message under the mouse. - Tests : ExchangeBackoff1614Tests. Verify.ps1 (agent) : 3335/3335, 0 avertissement, 0 erreur ; DLL 0.1614.0.0. Rien à essayer en jeu.
### English
- Review of the block 0.1607 to 0.1612, pre-existing finding M4: « at most once every 20 hours » held only for an exchange that ended; a discoveries exchange that failed (expired token, refusal, network) was tried again every 15 minutes, so GitHub was asked every 15 minutes for as long as it failed. Now the automatic exchange waits 15 minutes after a failure, then twice as long after each new failure in a row (30 minutes, 1 hour… 20 hours at most); the count and the last attempt's time are kept in github.json (a restart of the game does not try again at once); an exchange that ends clears the count (GitHubExchange.Wait). The setting's tip (en, fr) and SECURITY (en, fr) say so. Fewer requests only (R04), nothing else changes. X-666.

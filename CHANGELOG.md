# Journal des versions / Changelog

Résumé par version, en français puis `### English` (partie anglaise obligatoire depuis 0.219.0) ; la partie anglaise sert aussi de corps
aux commits et aux notes de release sur GitHub. Preuves citées : docs/evidence/.
Chaque version a été compilée et testée par `scripts/Verify.ps1` ; la validation en jeu est indiquée quand l'utilisateur l'a rapportée.
Ce fichier garde la dernière release et les versions qui suivent ; les plus anciennes sont dans [docs/changelog/](docs/changelog/)
(déplacées par `tools/changelog.py archive`, un fichier par centaine de versions).

## 0.1148.0

### English
- Player's data in SQLite (X-173, continued): the voyage history (submarines and airships, 180 days) moves into the data file TenshoData.db, after the gil journal and the achievement progress. One row per voyage, the history replaced whole in one transaction at each save (a stop in the middle leaves the last save whole). ## 0.1146.0

### English
- Shared discoveries, the maintainer's merge tool (X-168, audit of 12/11): GitHub drops the « discoveries » label of an issue opened by a player without rights on the repository; the tool no longer looks for that label alone: it reads every open issue and recognises a share by the label, the title « Discoveries: <account> » or the content (« Shared from Tensho Assistant » with a gist link). Before reading a gist, it checks there is one link only, the CC0-1.0 sharing is ticked, the title names the issue's author and the gist belongs to that author; otherwise the issue goes to manual triage, is never merged, and a comment in both languages tells the player why (`notice N manual …`).

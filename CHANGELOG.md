# Journal des versions / Changelog

Résumé par version, en français puis `### English` (partie anglaise obligatoire depuis 0.219.0) ; la partie anglaise sert aussi de corps
aux commits et aux notes de release sur GitHub. Preuves citées : docs/evidence/.
Chaque version a été compilée et testée par `scripts/Verify.ps1` ; la validation en jeu est indiquée quand l'utilisateur l'a rapportée.
Ce fichier garde la dernière release et les versions qui suivent ; les plus anciennes sont dans [docs/changelog/](docs/changelog/)
(déplacées par `tools/changelog.py archive`, un fichier par centaine de versions).

## 0.1262.0
- Plan global, X-161 : X-161 (demande de l'utilisateur du 12/11), carte de Tensho seulement : les repères d'exploration sont un peu plus petits par défaut (80 %) et les marques des monstres proches (listes, journal de chasse, ALÉA, magie bleue, collections…) moitié moins grandes (50 %). Une taille que le joueur a réglée reste : une valeur par défaut ne s'applique qu'à une icône absente du tableau enregistré, ce qui la donne aussi aux joueurs qui avaient déjà la carte. Les icônes au-dessus des têtes en jeu ne changent pas (réglage à part). Test de comportement : tableau enregistré avant cette version, taille choisie gardée, aller-retour. Test : MapIconSizes1262Tests.
- Pour les joueurs : Carte de Tensho : les repères d'exploration sont un peu plus petits et les marques des monstres proches moitié moins grandes par défaut ; les deux se règlent dans les tailles d'icônes de la carte.
- Tests : MapIconSizes1262Tests. Verify.ps1 (agent) : 2287/2287, 0 avertissement, 0 erreur ; DLL 0.1262.0.0. Non validé en jeu.
### English
- X-161 (user's request of 12/11), Tensho's map only: the sightseeing marks are a little smaller by default (80 %) and the marks of nearby monsters (lists, hunting log, FATEs, blue magic, collections…) half their size (50 %).

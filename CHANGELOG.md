## 0.1386.0
- Plan global, X-414 : Banque : effacement d'un personnage (commande du joueur) fait d'abord, quoi que tiennent les autres personnages, puis la banque relue vérifiée comme dans l'autre branche (renvoyée sans vérification depuis 0.1380, un recul) ; l'effet de bord de X-336 M12 est écrit là où il vit : une ligne d'un autre personnage qui ne passe pas les contrôles fait échouer tout l'enregistrement, rien d'écrit, comme Load échoue fermé sur les mêmes lignes. Tests de comportement BankValidation1386Tests sur un vrai fichier de données : un autre client enregistre 4 096 servants d'un autre personnage (valides seuls ; la liste entière en dépasse la borne de 4 096 entrées, une ligne illisible seule étant déjà refusée à la lecture), puis un changement (rien d'écrit) et un effacement (fait, banque relue refusée).
- Tests : BankValidation1386Tests. Verify.ps1 (agent) : 2622/2622, 0 avertissement, 0 erreur ; DLL 0.1386.0.0. Rien à essayer en jeu.
### English
- Bank: a character's erase (the player's command) is done first, whatever the other characters hold, then the bank read back is checked as in the other branch (returned unchecked since 0.1380, a regression); the side effect of X-336 M12 is written where it lives: a row of another character that fails the checks makes the whole save fail, nothing written, as Load fails closed on the same rows. Behaviour tests BankValidation1386Tests on a real data file: another client saves 4,096 retainers of another character (valid alone; the whole list exceeds its bound of 4,096 entries, a row unreadable alone being already refused when read), then a change (nothing written) and an erase (done, the bank read back refused).

### English
- Two game clients on one profile: discoveries add up (X-171, user's rule of 11/13 « add both »). Before, each client wrote the whole fact (DiscoveryDatabase.Write, upsert): with the same key, the last writer erased what the other had seen since its load. Now DiscoveryStore keeps, for each fact this client saw since its last write, the fact as it was before (null: new in this client); the write reads the row again in the same transaction (BEGIN IMMEDIATE: two clients never read the same row and both write it) and adds only what this client saw since (DiscoveryStore.AddMine): sightings, HQ sightings and values added; imported parts: the larger of the two (an import read by both is not counted twice); levels and dates widened, the first place kept, your own part joined.

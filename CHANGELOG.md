# Journal des versions / Changelog

Résumé par version, en français puis `### English` (partie anglaise obligatoire depuis 0.219.0) ; la partie anglaise sert aussi de corps
aux commits et aux notes de release sur GitHub. Preuves citées : docs/evidence/.
Chaque version a été compilée et testée par `scripts/Verify.ps1` ; la validation en jeu est indiquée quand l'utilisateur l'a rapportée.
Ce fichier garde la dernière release et les versions qui suivent ; les plus anciennes sont dans [docs/changelog/](docs/changelog/)
(déplacées par `tools/changelog.py archive`, un fichier par centaine de versions).

## 0.1238.0
- Plan global, X-151 : X-151 : contrat typé entre l'application de bureau et la fenêtre du plugin. Un seul fichier source (Desktop/DesktopSurface.cs) compilé dans le plugin, l'application et les tests : le plugin remplit chaque entrée depuis ses propres membres (MainWindow.DesktopSurfaceMap, entrées « required » : une entrée oubliée ou des paramètres changés cassent la compilation du plugin, plus l'application à l'exécution), l'application les relit typées. Seuls des délégués faits des types de .NET passent d'un côté à l'autre (le plugin est chargé depuis une copie réécrite : un type du plugin n'y serait pas le même). Pages (liste, page affichée, changement), pages laissées au jeu (la fenêtre cache ses propres entrées : plus de réflexion sur <Clone>$ ni sur un champ caché), mode bureau, données copiées, copies SQLite, alarmes, notification Windows, alertes du lien, quantités tenues et zone de la météo passent par là ; un seul nom reste atteint par réflexion pour elles (DesktopSurfaceMap, dans DesktopContract). Une entrée absente ou d'un autre type est dite au démarrage, remplacée par un défaut sans effet, et fait échouer l'essai sans fenêtre de Verify. Restent par leur nom : construction de la fenêtre (réglages, textes, lexique) et contrôles propres à l'essai sans fenêtre. Test : DesktopSurface1238Tests (comportement : aller-retour, entrée absente ou d'un autre type, types de .NET seulement, câblage) ; tests 1131, 1132, 1147, 1152, 1154, 1155, 1156, 1157, 1158 suivis.
- Tests : DesktopSurface1238Tests. Verify.ps1 (agent) : 2222/2222, 0 avertissement, 0 erreur ; DLL 0.1238.0.0. Non validé en jeu.
### English
- X-151: typed contract between the desktop application and the plugin's window. One source file (Desktop/DesktopSurface.cs) compiled into the plugin, the application and the tests: the plugin fills every entry from its own members (MainWindow.DesktopSurfaceMap, « required » entries: an entry left out or changed parameters break the plugin's build, no longer the application at run time), the application reads them back typed. Only delegates made of .NET's own types cross between the two (the plugin is loaded from a rewritten copy: a type of the plugin would not be the same there). Pages (list, page shown, change), pages kept in the game (the window hides its own entries: no more reflection on <Clone>$ or a hidden field), desktop mode, copied data, SQLite copies, alarms, Windows notification, link alerts, held counts and the weather zone go through it; one name is left reached by reflection for them (DesktopSurfaceMap, in DesktopContract). An entry absent or of another type is said at start, replaced by a harmless default, and fails Verify's headless run. Still by name: the window's construction (settings, texts, lexicon) and the headless run's own checks. Test: DesktopSurface1238Tests (behaviour: round trip, entry absent or of another type, .NET types only, wiring); tests 1131, 1132, 1147, 1152, 1154, 1155, 1156, 1157, 1158 follow.

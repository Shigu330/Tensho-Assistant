## 0.1475.0
- Plan global, X-493 : Relecture du bloc 0.1473 à 0.1474. Les statistiques de l'agent ne donnent plus un quota de 0 % par version quand le relevé, au pour cent près, ne bouge pas : elles disent « moins de x % » (borne haute) tant que l'écart mesuré n'est pas plus grand que l'erreur de lecture ; la consommation d'un relais est la plus haute lecture moins la première (une lecture recopiée plus basse ne l'efface plus) ; le débit ne compte que les versions des relais dont la durée est connue, et le quota par point ne divise que par les points des relais mesurés. Le test des noms privés écrit « NOTE private names: list absent … check not done » quand la liste n'est pas donnée (CI, Verify.ps1 lancé seul) au lieu de réussir en silence. Sonde HelpTextProbe : code mort retiré de Texts() et commentaire juste (une feuille illisible est nommée par l'appelant).
- Tests : PrivateNames1473Tests. Verify.ps1 (agent) : 2879/2879, 0 avertissement, 0 erreur ; DLL 0.1475.0.0. Rien à essayer en jeu.
### English
- Review of the block 0.1473 to 0.1474. The agent's statistics no longer give a quota of 0 % per version when the reading, to the whole percent, does not move: they say « under x % » (an upper bound) while the measured difference is not larger than the reading's error; a relay's use is its highest reading minus the first (a lower copied reading no longer erases it); the rate counts only the versions of relays whose duration is known, and the quota per point divides only by the measured relays' points. The private names test writes « NOTE private names: list absent … check not done » when the list is not given (CI, Verify.ps1 run alone) instead of passing in silence. HelpTextProbe: dead code removed from Texts() and an accurate comment (an unreadable sheet is named by the caller).

## 0.1474.0

- Tests : HelpTexts1474Tests. Verify.ps1 (agent) : 2879/2879, 0 avertissement, 0 erreur ; DLL 0.1474.0.0. Rien à essayer en jeu.
### English
- Tool (the user's request of 11/16 around 0:30 am, rule R06 completed): the game's own help, to search before any assumption or in-game reading. New read-only probe tools/HelpTextProbe: sheets (the 460 sheets with text), find (a text in every sheet), index (50 help, description and message sheets, French and English, with sheet, row, column and game version; 251,166 French texts on 11/16) and search (by words, accents ignored). The index is Square Enix data: kept outside the repository, made again after each patch, never copied into the plugin. The official online Play Guide of the Lodestone comes first for a subject it covers: read and cited by its link, never copied nor read by the plugin. Choice of the sheets recorded in docs/evidence/0.1474-help-texts.md (Beastmaster's labyrinth, aetherial wheels, Crafter's Grace); tools/README.md documents the probe.

## 0.1473.0
- Plan global, X-491 : Confidentialité (relecture 0.1472, I1 ; R04, R25) : le nom et le monde d'un joueur réel, et le début de son message, étaient écrits dans un commentaire du code (0.1471), dans le commentaire d'un test, dans le CHANGELOG et dans le texte du plan (X-472) ; le nom de personnage de l'utilisateur était 49 fois dans un ancien journal de preuve (0.160). Ils sont remplacés par « Name [world icon] World », « THE EXAMPLE » et « Joueur ». Garde-fou : le test PrivateNames1473Tests lit chaque fichier suivi (ou ajouté) et refuse tout nom d'une liste gardée hors du dépôt (son chemin donné par la variable TENSHO_PRIVATE_NAMES ; sans elle, comme dans la CI, la liste n'est pas lue ; donnée mais absente : échec) ; un échec nomme le fichier, la ligne et le numéro de l'entrée, jamais le nom. Les outils du mainteneur refusent un tel nom avant d'écrire un texte public. L'historique git n'est pas réécrit (décision de l'utilisateur). Avec lui, X-489 (produire à nouveau le plan dépassait son budget : 300 015 octets pour 300 000) : les points faits ont leur page, produite avec le plan global (docs/project/GLOBAL-PLAN-DONE.md, deux langues, budget de 400 Ko) ; GLOBAL-PLAN garde les points ouverts entiers et, sous chaque tableau, le nombre de ses points faits avec le lien vers leur section (214 758 octets) ; il ne grandit plus qu'avec les points ouverts. Test PlanCompact1092Tests (les deux pages et leurs budgets).
- Tests : PrivateNames1473Tests, PlanCompact1092Tests. Verify.ps1 (agent) : 2877/2877, 0 avertissement, 0 erreur ; DLL 0.1473.0.0. Rien à essayer en jeu.
### English
- Privacy (review of 0.1472, I1; R04, R25): a real player's name and world, and the start of their message, were written in a comment of the code (0.1471), in a test's comment, in the CHANGELOG and in the plan's text (X-472); the user's own character name was in an old evidence log 49 times (0.160). They now read « Name [world icon] World », « THE EXAMPLE » and « Joueur ». Guard: the test PrivateNames1473Tests reads every tracked (or added) file and refuses any name of a list kept out of the repository (its path given by the TENSHO_PRIVATE_NAMES variable; without it, as in the CI, the list is not read; given but missing: a failure); a failure names the file, the line and the entry's number, never the name. The maintainer's tools refuse such a name before writing a public text. The git history is not rewritten (the user's decision). With it, X-489 (producing the plan again went over its budget: 300,015 bytes for 300,000): the done points have their page, produced with the global plan (docs/project/GLOBAL-PLAN-DONE.md, both languages, a 400 KB budget); GLOBAL-PLAN keeps the open points whole and, under each table, the count of its done points with the link to their section (214,758 bytes); it grows with the open points only. Test PlanCompact1092Tests (both pages and their budgets).

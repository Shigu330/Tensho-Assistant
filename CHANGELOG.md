## 0.1736.0
- Plan global, X-732 : Fenêtre de chat Tensho, effacement (X-732, bug signalé par l'utilisateur le 21/11 vers 15 h 20, capture du réglage « S'effacer après » à 10 s : la fenêtre effacée ne revenait pas quand un message arrivait). Cause : ImGui ne dessine rien d'une fenêtre dont l'opacité vaut 0 à son ouverture, et les lignes des onglets ne se rafraîchissaient que dans le contenu de la fenêtre : effacée, elle ne voyait plus les nouveaux messages de son onglet. L'effacement (calculé avant le contenu) prend maintenant le message le plus récent de l'onglet affiché dans les données du chat (ChatFadeClock) : un nouveau message de l'onglet affiché la fait revenir, même sans dessin. Nouveau réglage, coupé par défaut, « Revenir aussi pour un message privé ou une alerte » : un message privé reçu ou un message avec une alerte (votre prénom dit par un joueur, un mot d'alerte) dans n'importe quel onglet la fait revenir aussi ; jamais ce que vous envoyez, jamais une ligne de combat. L'info-bulle de « S'effacer après » dit quels messages la font revenir. Mode développeur : comment la fenêtre est revenue (dix lignes au plus par session, jamais les mots d'un message). Textes en et fr.
- Pour les joueurs : fenêtre de chat : une fois effacée, elle revient quand un message arrive dans l'onglet affiché ; une nouvelle option la fait aussi revenir pour un message privé ou une alerte.
- Tests : ChatFade1736Tests. Verify.ps1 (agent) : 3707/3707, 0 avertissement, 0 erreur ; DLL 0.1736.0.0. Non validé en jeu.
### English
- Tensho chat window, fading out (X-732, bug reported by the user on 21/11 around 15:20, screenshot of the « Fade out after » setting at 10 s: once faded out, the window did not come back when a message arrived). Cause: ImGui draws nothing of a window whose opacity is 0 when it opens, and the tabs' lines were refreshed only in the window's content: faded out, it no longer saw its tab's new messages. The fade (computed before the content) now takes the newest message of the tab shown from the chat's data (ChatFadeClock): a new message of the tab shown brings it back, with nothing drawn. New setting, off by default, « Also come back for a tell or an alert »: a tell received or a message holding an alert (your first name said by a player, an alert word) in any tab brings it back too; never what you send, never a combat line. The tooltip of « Fade out after » says which messages bring it back. Developer mode: how the window came back (ten lines at most per session, never a message's words). Texts in en and fr.
- For players: Chat window: once faded out, it comes back when a message arrives in the tab shown; a new option also brings it back for a tell or an alert.

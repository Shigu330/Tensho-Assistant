## 0.1374.0
- Plan global, X-405 : Vocabulaire français (choix recommandés des décisions D-170 et D-171, appliqués en attendant la réponse de l'utilisateur) : « duty » se dit « mission » partout, le nom du client (Addon#2225.0, #3770.0, #11170.0, MainCommand#43.5) : la page devient « Butin des missions », le réglage de la carte « Masquer en mission » ; « contenu » ne garde que le groupe CONTENUS, le contenu classé et le contenu d'un sac ou du presse-papiers. Un PNJ qui vend est un « marchand » (Addon#3408.0, #7610.0, MainCommand#71.6) : la page et l'outil s'appellent partout « PNJ marchands » ; « vendeur » reste le joueur du tableau des ventes (Addon#6996.0). En anglais, « merchant directory » et « Shopkeepers » s'alignent sur « vendor ».
- Pour les joueurs : textes français : les contenus s'appellent « missions » et les PNJ vendeurs « marchands » partout, comme dans le jeu.
- Tests : Vocabulary1374Tests. Verify.ps1 (agent) : 2583/2583, 0 avertissement, 0 erreur ; DLL 0.1374.0.0. Non validé en jeu.
### English
- French vocabulary (recommended choices of decisions D-170 and D-171, applied while the user has not answered): « duty » is « mission » everywhere, the client's name (Addon#2225.0, #3770.0, #11170.0, MainCommand#43.5): the page becomes « Butin des missions », the map's setting « Masquer en mission »; « contenu » keeps only the CONTENUS group, ranked content and the contents of a bag or the clipboard. An NPC who sells is a « marchand » (Addon#3408.0, #7610.0, MainCommand#71.6): the page and the tool are « PNJ marchands » everywhere; « vendeur » stays the market-board player (Addon#6996.0). In English, « merchant directory » and « Shopkeepers » are aligned on « vendor ».
- For players: French texts: duties are called « missions » and NPC vendors « marchands » everywhere, as in the game.

## 0.1372.0
- Plan global, X-404 : Mandats : le nom du client ne répète plus « Client : ». La feuille LeveClient porte déjà ce libellé devant chaque nom (anglais « Client: », français « Client : », allemand « Auftraggeber: » ou « Auftraggeberin: », aucun en japonais ; preuve docs/evidence/0.1372-leve-client-label.md) : il est trouvé dans la feuille elle-même et retiré une fois, pour l'infobulle, la colonne et le filtre. L'entrée du menu « Éthérite la plus proche du client » visait en fait le PNJ de LevelLevemete (responsable des mandats, sergent de grande compagnie ou PNJ de livraison selon le mandat) : elle dit maintenant « Éthérite la plus proche du PNJ du mandat ».
- Pour les joueurs : mandats : les noms des clients ne répètent plus « Client : », et l'entrée de carte dit qu'elle vise le PNJ du mandat.
- Tests : LeveClient1372Tests. Verify.ps1 (agent) : 2579/2579, 0 avertissement, 0 erreur ; DLL 0.1372.0.0. Non validé en jeu.
### English
- Guildleves: the client's name no longer repeats « Client: ». The LeveClient sheet already writes that label before each name (English « Client: », French « Client : », German « Auftraggeber: » or « Auftraggeberin: », none in Japanese; evidence docs/evidence/0.1372-leve-client-label.md): it is found from the sheet itself and taken off once, for the tooltip, the column and the filter. The menu entry « Nearest aetheryte to the client » in fact pointed at the LevelLevemete NPC (a levemete, a Grand Company sergeant or a delivery NPC depending on the leve): it now says « Nearest aetheryte to the leve's NPC ».
- For players: Guildleves: client names no longer repeat « Client: », and the map entry now says it points to the leve's NPC.

## 0.1371.0
- Plan global, X-373 : Tests : le test « Settings saver 1164 : le déchargement écrit ce qui reste » ne dépend plus d'un délai réel. L'écriture en cours est retenue par une porte que le test ouvre lui-même, au lieu de 400 ms de vrai temps qu'une machine de la CI lente pouvait dépasser (échec « the wait ran out », CI de 0.1354.0). Même comportement vérifié : l'attente expire, rien n'est écrit tant que la porte est fermée, puis les réglages vivants finissent sur le disque, sans écriture simultanée.
- Tests : SettingsSaver1164Tests. Verify.ps1 (agent) : 2576/2576, 0 avertissement, 0 erreur ; DLL 0.1371.0.0. Rien à essayer en jeu.
### English
- Tests: the test « Settings saver 1164: unload writes what is left » no longer depends on a real delay. The write under way is held by a gate the test opens itself, instead of 400 ms of real time that a slow CI machine could outlast (failure « the wait ran out », CI of 0.1354.0). Same behaviour checked: the wait runs out, nothing is written while the gate is shut, then the live settings end on disk, never two writes at once.

## 0.1370.0
- Plan global, X-367 : Échange des découvertes : quand GitHub ne répond pas, refuse la demande, dépasse son délai ou n'a pas encore publié le fichier commun, la page dit « GitHub injoignable ou fichier commun pas encore publié, réessayez plus tard » au lieu de « Fichier commun illisible » (relecture du bloc 0.1346 à 0.1349, M1 ; décision D-159). - Tests : CommonUnreachable1370Tests. Verify.ps1 (agent) : 2576/2576, 0 avertissement, 0 erreur ; DLL 0.1370.0.0. Non validé en jeu.
### English
- Discoveries exchange: when GitHub does not answer, refuses the request, runs past its delay or has not published the common file yet, the page says « GitHub could not be reached or the common file is not published yet; try again later » instead of « Common file unreadable » (review of block 0.1346 to 0.1349, M1; decision D-159). A file that is really damaged (unreadable JSON, wrong hash) still says « unreadable ». Outside the version: the agent's cleanliness tool refuses a mistyped mode or option (M2) and a failed selftest of it, as of the guard, stops the publication (M3); the load-test generator of the merge tool follows the X-183 rules and its selftest passes (X-362).
- For players: Discoveries exchange: when GitHub cannot be reached, the page now says to try again later instead of calling the common file unreadable.

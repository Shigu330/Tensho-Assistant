# Journal des versions / Changelog

Résumé par version, en français puis `### English` (partie anglaise obligatoire depuis 0.219.0) ; la partie anglaise sert aussi de corps
aux commits et aux notes de release sur GitHub. Preuves citées : docs/evidence/.
Chaque version a été compilée et testée par `scripts/Verify.ps1` ; la validation en jeu est indiquée quand l'utilisateur l'a rapportée.
Ce fichier garde la dernière release et les versions qui suivent ; les plus anciennes sont dans [docs/changelog/](docs/changelog/)
(déplacées par `tools/changelog.py archive`, un fichier par centaine de versions).

## 0.1224.0
- Application de bureau, état de mise à jour (update.json) : le Verify de 0.1223 a échoué une fois sur « Desktop install 1117 » (« Access to the path is denied » dans File.Move) : un autre programme (antivirus, indexeur, lecteur sans partage de suppression) peut tenir update.json un instant juste après son écriture, et le déplacement à sa place n'était pas réessayé. Vaut pour le plugin (installation depuis Paramètres, réglage de mise à jour automatique) et l'application. Test de comportement : UpdateStateHeld1224Tests (fichier tenu 150 ms puis relâché : attendu et gardé ; tenu longtemps : erreur rendue, ancien état entier, aucun temporaire).
- Tests : UpdateStateHeld1224Tests. Verify.ps1 (agent) : 2183/2183, 0 avertissement, 0 erreur ; DLL 0.1224.0.0. Rien à essayer en jeu.
### English
- Desktop app, update state (update.json): the Verify of 0.1223 failed once on « Desktop install 1117 » (« Access to the path is denied » in File.Move): another program (antivirus, indexer, reader without delete sharing) can hold update.json an instant just after it was written, and the move into place was not tried again.

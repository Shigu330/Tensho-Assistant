## 0.1224.0
- Application de bureau, état de mise à jour (update.json) : le Verify de 0.1223 a échoué une fois sur « Desktop install 1117 » (« Access to the path is denied » dans File.Move) : un autre programme (antivirus, indexeur, lecteur sans partage de suppression) peut tenir update.json un instant juste après son écriture, et le déplacement à sa place n'était pas réessayé.

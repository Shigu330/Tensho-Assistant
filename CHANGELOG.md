## 0.1716.0
- Plan global, X-716 : Fenêtre de chat Tensho, réglages (X-716, demande de l'utilisateur du 21/11 vers 11 h 35) : les listes du chat (joueurs cachés, joueurs mis en avant, mots d'alerte, mots à garder ou à cacher d'un onglet) s'affichent dans une zone de hauteur fixe (8 lignes) avec sa barre de défilement : la page des réglages ne s'allonge plus avec la liste. La limite des listes de joueurs et des mots d'alerte passe de 600 à 6000 caractères, environ deux cent cinquante noms (les mots d'un onglet restent à 300). Une liste pleine le dit sous sa boîte (ce qui a été tapé reste) et grise les entrées « Cacher » et « Mettre en avant » du menu d'un joueur avec la raison : jamais un ajout perdu en silence. ChatTextFilter.TryAdd (pur).
- Pour les joueurs : réglages de la fenêtre de chat : les longues listes (joueurs cachés, mots d'alerte…) défilent dans leur propre zone, gardent environ deux cent cinquante noms et disent quand elles sont pleines.
- Tests : ChatLists1716Tests. Verify.ps1 (agent) : 3641/3641, 0 avertissement, 0 erreur ; DLL 0.1716.0.0. Non validé en jeu.
### English
- Tensho chat window, settings (X-716, the user's request of 21/11 around 11:35): the chat's lists (hidden players, players put forward, alert words, a tab's words to keep or hide) are shown in an area of fixed height (8 lines) with its own scroll bar: the settings page no longer grows with the list. The limit of the player lists and of the alert words goes from 600 to 6000 characters, about two hundred and fifty names (a tab's words stay at 300). A full list says so under its box (what was typed stays) and greys the « Hide » and « Put forward » entries of a player's menu with the reason: never an addition lost silently. ChatTextFilter.TryAdd (pure).
- For players: Chat window settings: long lists (hidden players, alert words…) scroll in their own area, hold about two hundred and fifty names, and say when they are full.

## 0.1715.0
- Plan global, X-473 : Fenêtre de chat Tensho, info-bulles (X-473, 2e partie : les statuts). Un statut que le jeu met en lien dans un message (le lien du jeu, celui qui montre l'info-bulle dans le chat du jeu : StatusPayload de Dalamud, un nom sûr) est gardé comme lien de statut : le texte reste celui du message, sans flèche ni soulignement, et au survol l'info-bulle du jeu : son icône, son nom et sa description (feuille Status, langue du client). Un statut que la feuille ne nomme pas n'a pas d'info-bulle (jamais une fausse). Affichage seulement : rien n'est compté ni gardé (R03.1). L'historique garde un statut lié comme son texte. Les actions n'ont pas de lien du jeu (aucun type de lien d'action dans Dalamud 15) : en mode développeur, le journal décrit désormais les morceaux d'une ligne de combat (une par genre, trente au plus par session ; sortes et longueurs seulement, jamais les mots) pour apprendre comment le jeu envoie leurs noms avant toute info-bulle (R06). X-473 reste ouvert pour les actions.
- Pour les joueurs : fenêtre de chat : survoler un effet nommé dans un message (« bénéficie de l'effet … ») montre son icône, son nom et sa description, comme dans le chat du jeu.
- Tests : ChatStatus1715Tests. Verify.ps1 (agent) : 3639/3639, 0 avertissement, 0 erreur ; DLL 0.1715.0.0. Non validé en jeu.
### English
- Tensho chat window, tooltips (X-473, part 2: statuses). A status the game links in a message (the game's link, the one that shows its tooltip in the game's chat: Dalamud's StatusPayload, a sure name) is kept as a status link: its text stays the message's, without arrow or underline, and on hover the game's tooltip: its icon, name and description (Status sheet, the client's language). A status the sheet does not name has no tooltip (never a false one). Display only: nothing counted or kept (R03.1). The history keeps a linked status as its text. Actions have no link of the game (no action link type in Dalamud 15): in developer mode, the log now describes the pieces of a combat line (one per kind, thirty at most per session; kinds and lengths only, never the words) to learn how the game sends their names before any tooltip (R06). X-473 stays open for the actions.
- For players: Chat window: hovering a status named in a message (« gains the effect of … ») shows its icon, name and description, as in the game's chat.

## 0.1714.0

- Tests : ChatDetached1714Tests. Verify.ps1 (agent) : 3636/3636, 0 avertissement, 0 erreur ; DLL 0.1714.0.0. Non validé en jeu.
### English
- Tensho chat window, X-447 B11 and B12 (the user's choices of 15/11). B11: a right click on a tab, « Detach into a window of its own », puts it in a separate window beside the chat window (up to 4, each keeping its place and size; the chat window always keeps at least one tab): at its top, a button that puts it back and its name with its unread count (a right click menu: put back, clear, close a conversation, hide all); then its pinned messages and its lines, drawn by the chat window's own code (links, menus, copy, text selection, scrolling, the tab's text size), with the chat window's look (background, frame, lock, text opacity). Its cross puts it back too. A detached conversation is never replaced. Hidden as the chat window (PvP and ranked play, the game's interface hidden, combat, cutscene, duty, a context's profile without that tab), and behind a game window as the other panels. B12 (WIM's « Exposé »): « /tensho chat hide », or the entry « Hide every chat window for a moment » of a tab's menu (while a tab is detached) or of a detached window's name, hides every Tensho chat window for a moment, closing nothing (the messages still arrive); « /tensho chat », the same command or a click on the server bar's alert shows them back. Nothing is sent to the game (R03.3). Command help and FAQ completed. ChatWindows (pure); ChatTabSettings.Window saved with the tab.
- For players: Chat window: a tab can be detached into a window of its own (right click on the tab), and « /tensho chat hide » hides every chat window for a moment.

# MAP-002 — repères favoris persistants

Date : 2026-10-28 Europe/Brussels. Version 0.19.0. État : IMPLEMENTED / TESTED, rendu en jeu non validé.

Contexte : l'utilisateur reporte le test Macro Chain (« Je testerai plus tard »). Ce retour ne valide ni n'annule les macros ; leur protocole reste conservé dans MACRO-001A.md. Une tranche indépendante complète Mappy.

Capacités : jusqu'à 200 favoris globaux dans Configuration v1, identifiant stable, nom de 1–80 caractères, paire MapId/TerritoryId et coordonnées exactes. Ajout depuis la carte sélectionnée ; chargement et ouverture via une icône ; modification du nom/position ; retrait explicite. Les favoris sont partagés entre les personnages et n'impliquent pas de déblocage de zone.

Un favori absent du nouveau catalogue, au territoire incohérent ou aux coordonnées invalides n'est pas ouvert. Il reste sauvegardé et peut être retiré ; aucune suppression silencieuse lors d'une mise à jour du jeu. Les vues et opérations sont copiées ; un échec de sauvegarde restaure la liste précédente. Le chargement d'une configuration ancienne donne une liste vide.

Les opérations locales ne font aucune lecture native et n'ouvrent aucune carte automatiquement. Le clic d'ouverture utilise le même helper que le navigateur existant et la paire résolue dans le catalogue. Liste défilante avec clipper, icône empruntée à la police Dalamud, noms littéraux et coordonnées en infobulle. Aucune texture, callback ou tâche supplémentaire.

Tests ajoutés : aller-retour JSON, migration v1, identité et coordonnées ; copies et immutabilité ; modification/retrait ; noms/coordonnées/bornes/doublons ; conservation des références de carte indisponibles ; refus de réinterpréter un MapId sous un autre territoire ; rollback de sauvegarde et absence de persistance après édition invalide. Verify.ps1 : 119/119 tests, Release et package 0.19.0 valides.

Essai facultatif ultérieur : Accueil & outils → Mappy, choisir une carte et X/Y, nommer puis Ajouter aux favoris. Charger/ouvrir le repère, modifier ses coordonnées puis Mettre à jour, recharger le plugin et vérifier sa conservation ; retirer un repère choisi. Aucun de ces essais n'est revendiqué exécuté. Le test Macro Chain n'est pas redemandé.

# R-11 — Planificateurs d'équipement (demande utilisateur 2026-11-02)

## Demande
- Un planificateur d'équipement pour le personnage, dans le style FF14, avec une fenêtre comme la fenêtre Personnage.
- Il donne accès à l'équipement proche du niveau du personnage.
- Il a des filtres réglables : par exemple, hors des niveaux 50, 60, 70, 80, 90 et 100, ne voir que l'équipement du niveau exact.
- Il affiche les statistiques réelles.
- Il permet d'essayer l'équipement, et l'essayage doit être disponible partout où l'apparence compte (« fashion »).
- Il permet de partager les builds.
- Le même style vaut pour les dirigeables, les sous-marins et tout ce qui a un équipement utile.

## Références (lues, jamais copiées)
- Données du jeu d'abord, pour l'objet, l'emplacement, le job, le niveau et les statistiques :
  - feuilles Item, EquipSlotCategory, ClassJobCategory, BaseParam et Materia ;
  - équipement porté lu dans InventoryType.EquippedItems.
- HimbeertoniRaidTool (MIT) : comparaison d'équipement en raid.
- Glamourer (Apache-2.0) : apparence.
- xivgear.app : aucune licence publiée, donc lecture seulement.
- SubmarineTracker (MIT) : montages de sous-marins, pour l'étape 3.

## Étapes
1. **FAIT 0.310** : page Équipement façon fenêtre Personnage.
   - Emplacements à gauche et à droite.
   - Statistiques au milieu : actuelles (lues dans le jeu), prévues, écart, et valeurs dérivées pour les jobs de combat.
   - Liste de choix par emplacement selon le job et le niveau, avec filtres réglables (infobulle et ↺) :
     écart de niveau, niveau exact hors paliers, niveau d'objet minimum, HQ supposé.
   - Plan enregistré par job.
   - Essayage : bouton « Essayer le plan », et « Essayer » dans le menu clic droit de tout équipement affiché par Tensho.
   - Partage : code « TENSHO-GEAR1: » avec la liste lisible, et import depuis le presse-papiers.
1b. **FAIT 0.311** : filtre « Tous les jobs (mirage) » (règle du patch 7.4), pièces « Mirage » (apparence seulement).
1c. **FAIT 0.312** : matérias sur l'équipement porté et prévu, plafonds par pièce, surmatérialisation, partage.
2. **FAIT 0.314** : sources et possession :
   - d'où vient chaque pièce (marchand, artisanat, donjon), en réutilisant le menu Sources ;
   - ✓ si la pièce est déjà possédée (inventaire, armurerie, Banque), filtre « Seulement ce que je possède », section « Pièces à obtenir ».
3. **FAIT 0.315** (sauf planificateur de trajets de dirigeable, faute de données sous licence) : sous-marins et dirigeables, dans le même style :
   - quatre emplacements (coque, poupe, proue, passerelle) ;
   - feuilles SubmarinePart et AirshipExplorationPart, rang, bonus de rang ;
   - statistiques réelles lues dans l'atelier ;
   - meilleur montage pour un trajet choisi (lien avec l'onglet Meilleurs trajets).
4. Autres équipements (décision 2026-11-02, DEC-023) : barde de chocobo, puis escouade (sonder d'abord ce que le jeu permet
   d'équiper) ; récolte et artisanat sont déjà couverts par les jobs de l'étape 1.
   - FAIT 0.340 : section « Barde de chocobo » de la page Équipement (barde portée, bardes débloquées, objet qui apprend chacune ;
     docs/evidence/0.340-chocobo-barding.md).
   - Escouade : apparence seulement, rien à planifier ; retirée (défaut recommandé, à confirmer à la fin).

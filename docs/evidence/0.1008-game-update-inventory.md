# What a game update can break (0.1008, 2026-11-09)

User request (2026-11-09, FF14 update coming, Dalamud to follow): « inventory first »: list what the update can break, so that after it we
check the right places instead of searching. Read from the code of 0.1007 (`src/TenshoAssistant`), nothing run in game.
`GameUpdateInventory1008Tests` fails when the code uses a native function, a native singleton or a game window by name that is not listed here.

## Summary

- No hand-written memory offset, no signature scan: every native access goes through FFXIVClientStructs (15.0.3.9) and Dalamud services.
  A game update is therefore fixed upstream first (new Dalamud, new FFXIVClientStructs); Tensho then only rebuilds and checks.
- Every native function called through a pointer checks the pointer first (`MemberFunctionPointers.X != 0`); an unresolved function makes
  the feature say « unavailable » instead of crashing (46 functions below).
- Two hooks only (`ActionManager.UseAction`, `RaptureShellModule.ExecuteMacro`), both through `HookFromAddress` after the same check.
- If Dalamud raises its API level with the update (Tensho is on API 15, `Dalamud.NET.Sdk` 15), Dalamud lists Tensho as outdated until it is
  rebuilt with the new SDK; renamed or removed members then show as build errors, not in game.

## Risk 4: the game's data sheets

Columns renamed or removed in Lumina are build errors after the package update. Changes in the rows are reported in game by the check of
0.972 (`Diagnostics/GameDataWatch`, « Game data check: » lines, 37 watched sheets, « to look at » for the sheets Tensho keeps a table of:
expansions, S ranks, ocean fishing routes, festivals, content types). Community tables (S rank conditions, ocean fishing times, festival
names) can lag behind the update; the check names them.

## After the update, in order

1. Wait for Dalamud (and FFXIVClientStructs) for the new game version; Tensho is not loaded before.
2. If the API level changed: new SDK and packages, `.\scripts\Verify.ps1` green, new version. Patch 7.58 (2026-11-10) is minor: API 15 stays; API 16
   comes with the next major patch, its port is listed in `docs/evidence/0.1009-dalamud-api16-watch.md`.
3. Load in game in developer mode; the agent reads the `Selftest` and « Game data check: » lines and compares them with the baseline above.
4. Risk 1, one action at a time with the user; then the windows of risk 3 as they are met while playing.

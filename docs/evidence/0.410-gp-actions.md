# 0.410 — R-09 : actions de récolte ajoutées à l'optimiseur PR (sonde en lecture seule)

Commande : `PROBE_GPACTIONS=1 dotnet tools/ShopCurrencyProbe/bin/Release/net10.0/ShopCurrencyProbe.dll "<sqpack>"` (feuilles Action,
ActionTransient, Trait, TraitTransient et Status ; noms anglais / français ; accents remplacés par « � » dans la console).

- Raison solide (mineur, 232) / Sagesse du fermier (botaniste, 215) : niveau 25, 300 PR, « Grants another gathering attempt ».
- Vision claire (4072) / Maîtrise florale (4086) : niveau 23, 50 PR, +15 % sur l'essai suivant, sans effet sur un objet à 0 %.
- Trait niveau 90 « Enhanced Solid Reason » / « Enhanced Ageless Words » : 50 % de chance d'Eurêka après Raison solide / Sagesse du fermier.
- Étalage des connaissances (26521 / 26522) : niveau 90, 0 PR, un essai de plus, seulement sous Eurêka (statut 2765). Hors catalogue
  (pas de coût en PR) : l'optimiseur compte en moyenne 0,5 essai de plus par Raison solide à partir du niveau 90.
- Le chargeur du catalogue vérifie toujours chaque action dans la feuille du jeu (métier, niveau, coût en PR) et refuse le catalogue sinon.

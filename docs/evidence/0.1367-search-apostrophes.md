Item 8090 reads « poignée de plumes d'Ehcatl » (straight apostrophe, no soft hyphen). Tensho's own texts use the straight apostrophe
since 0.1354 (D-162). A curly apostrophe can therefore only come from what the player types; since 0.1367 every search of Tensho folds
the apostrophe forms to the straight one (`SearchText`), on both sides.

The in-game report of 15/11 (test T-0.1354-1) was made on the Discoveries page, whose search covers only the facts noted (monsters,
FATEs, item sources seen): an item without a noted fact is not listed there whatever the apostrophe. The Items page and the quick
search look in the whole item list.

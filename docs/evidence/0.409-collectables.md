# 0.409 — R-06 : collectionnables (sonde en lecture seule)

Commande : `PROBE_COLLECTABLES=1 dotnet tools/ShopCurrencyProbe/bin/Release/net10.0/ShopCurrencyProbe.dll "<sqpack>"` (client français,
Lumina, aucune donnée du jeu modifiée). Lettres accentuées remplacées par « ? » ou « � » dans la sortie console.

## Fenêtre du jeu
FFXIVClientStructs `AddonGatheringMasterpiece` (ApiProbe, métadonnées) : champs nommés `ItemName`, `ObtainChance`, `GPLeftover`, `GPTotal`,
`IntegrityLeftover`, `IntegrityTotal`, `IntegrityGauge`, glisser-déposer des actions (Scour, Brazen, Meticulous, Scrutiny, Collector's Focus,
Priming Touch, Collect). **Aucun champ nommé pour la collectabilité en cours** : inconnue ; le mode développeur liste les AtkValues de la
fenêtre pour la trouver pendant la campagne de tests en jeu. Aucune action conseillée tant qu'elle n'est pas lue.

## Feuilles
- `CollectablesShopItem` (sous-lignes) : Item, LevelMin, LevelMax, CollectablesShopRefine, CollectablesShopRewardScrip, groupe, Stars.
- `CollectablesShopRefine` : LowCollectability, MidCollectability, HighCollectability (lignes à 0/0/0 : pas de remise, écartées).
- `CollectablesShopRewardScrip` : Currency, LowReward, MidReward, HighReward. **Currency non relié à un type d'assignat** (valeurs 0, 2, 4, 6, 7) :
  le type n'est pas affiché.
- `CollectablesShop` : RewardType 1 = boutiques sans nom dont les groupes sont les niveaux de remise (« Nv 50-60 »…) ; RewardType 2 =
  « Composants d'affinage… », « …outils resplendissants » (récompenses en objets). Tensho n'affiche des assignats que pour RewardType 1
  (déduit de ce contenu, à confirmer en jeu).

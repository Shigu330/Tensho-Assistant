# 0.1559 · What an enemy's action inflicts in the Crucible (X-486)

Game 2026.11.03.0000.0000, read with `tools/XbmProbe` (French client), 20/11.

`XBMBattleDetailAction` has four columns: 0 the `Action` row (0.500-xbm-columns.md), 1 the target (`XBMActionTarget`), 2 the shape
(`XBMActionEffectType`), 3 a `UInt32` not read before 0.1559. Its values are `Status` rows, each an effect such an action inflicts:

Every non-zero value tried is a `Status` row whose name and description fit an action of a fight (damage over time, a bonus, a barrier,
a doom); 0 is an action with no effect. The plugin shows that status's name, in the client's language, after the action
(`BoardAction.Effect`, « inflige : Poison »). Shown only, as the game's own board window does before the fight (R03.1).

Not read: whether an action can be interrupted. No column of these sheets is established for it (0.1529-beast-fight-shown.md).

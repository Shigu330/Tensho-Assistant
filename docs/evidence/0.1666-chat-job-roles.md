# 0.1666: role colours and job icons in the Tensho chat (X-690)

English first, then French.

## English

- Roles: ClassJob sheet, Role column (Lumina `ClassJob.Role`), French client 2026.11.03, XbmProbe of 21/11: 1 for Gladiator, Marauder,
  Paladin, Warrior, Dark Knight, Gunbreaker (tanks); 4 for Conjurer, White Mage, Scholar, Astrologian, Sage (healers); 2 for Pugilist,
  Lancer, Monk, Dragoon, Rogue, Ninja, Samurai, Reaper, Viper, Beastmaster (melee); 3 for Archer, Thaumaturge, Bard, Black Mage, Arcanist,
  Summoner, Machinist, Red Mage, Blue Mage, Dancer, Pictomancer (ranged and casters); 0 for the adventurer, crafters and gatherers.
  The plugin already reads 1 tank and 4 healer for the character page (StatFormulas).
- Role colours: the game's own chat settings. Its help texts (Addon 15814 « Role Color Settings », 15815 « Apply colors according to player
  roles. », 7973 « Apply colors according to role. »); Dalamud's UiConfigOption (ApiProbe, Dalamud 15.0.4.1): LogSetRoleColor 379,
  LogColorRoleTank 380, LogColorRoleHealer 381, LogColorRoleDPS 382. Their values in the character's COMMON.DAT (read 21/11): LogColorRoleTank
  4278223103 = 0xFF0080FF (blue), LogColorRoleHealer 4286642272 = 0xFF80F860 (green), LogColorRoleDPS 4294934399 = 0xFFFF807F (red): the
  format is 0xAARRGGBB. These three are Tensho's defaults when the option cannot be read.
- Job icons: 62100 + ClassJob row, already used by the map (party members) and the gathering and crafting panels.
- Who: your party (Dalamud IPartyList: name, world, ClassJob), your alliance (FFXIVClientStructs GroupManager.MainGroup.AllianceMembers:
  NameString, HomeWorld, ClassJob, read only when IsAlliance; ApiProbe of 21/11), the characters nearby (the object table). Read once a second
  on the framework thread, in memory only, cleared at logout and unload; nothing read during a cut (PvP, ranked contents). A sender's job is
  the one the game shows when the message arrives, kept with the message's sender in memory; never written to the chat history.
- Not proven yet: in game, the colours and icons against the game's own chat in a party and an alliance (test of 0.1666).

## Français

- Rôles : feuille ClassJob, colonne Role (`ClassJob.Role` de Lumina), client français 2026.11.03, XbmProbe du 21/11 : 1 pour gladiateur,
  maraudeur, paladin, guerrier, chevalier noir, pistosabreur (tanks) ; 4 pour élémentaliste, mage blanc, érudit, astromancien, sage
  (soigneurs) ; 2 pour pugiliste, maître d'hast, moine, chevalier dragon, surineur, ninja, samouraï, faucheur, rôdeur vipère, dresseur
  (mêlée) ; 3 pour archer, occultiste, barde, mage noir, arcaniste, invocateur, machiniste, mage rouge, mage bleu, danseur, pictomancien
  (distance et lanceurs de sorts) ; 0 pour l'aventurier, les artisans et les récolteurs. Le plugin lit déjà 1 tank et 4 soigneur pour la
  page du personnage (StatFormulas).
- Couleurs de rôle : les réglages du chat du jeu. Ses textes (Addon 15814 « Affichage des couleurs de rôles », 15815 « Attribue à chaque
  message la couleur du rôle de son auteur », 7973 « Appliquer les couleurs de rôles ») ; UiConfigOption de Dalamud (ApiProbe, Dalamud
  15.0.4.1) : LogSetRoleColor 379, LogColorRoleTank 380, LogColorRoleHealer 381, LogColorRoleDPS 382. Leurs valeurs dans le COMMON.DAT du
  personnage (lu le 21/11) : LogColorRoleTank 4278223103 = 0xFF0080FF (bleu), LogColorRoleHealer 4286642272 = 0xFF80F860 (vert),
  LogColorRoleDPS 4294934399 = 0xFFFF807F (rouge) : le format est 0xAARRGGBB. Ces trois valeurs sont celles de Tensho quand le réglage ne se
  lit pas.
- Icônes de classe : 62100 + ligne de ClassJob, déjà utilisées par la carte (membres de l'équipe) et les panneaux de récolte et
  d'artisanat.
- Qui : votre équipe (IPartyList de Dalamud : nom, monde, ClassJob), votre alliance (GroupManager.MainGroup.AllianceMembers de
  FFXIVClientStructs : NameString, HomeWorld, ClassJob, lus seulement si IsAlliance ; ApiProbe du 21/11), les personnages proches (la table
  des objets). Lu une fois par seconde sur le thread du jeu, en mémoire seulement, effacé à la déconnexion et au déchargement ; rien n'est lu
  pendant une coupure (JcJ, contenus classés). La classe d'un auteur est celle que le jeu montre à l'arrivée du message, gardée avec
  l'auteur du message en mémoire ; jamais écrite dans l'historique du chat.
- Pas encore prouvé : en jeu, les couleurs et les icônes comparées au chat du jeu en équipe et en alliance (essai de 0.1666).

# 0.226 — Coordonnées des lieux de pêche (FishingSpot)

Sonde en lecture seule `tools/ShopCurrencyProbe`, mode `PROBE_FISHSPOT=35` (données du jeu, 2026-11-01) :

    FISHSPOT 35 'Limsa Lominsa - L'Entrepont' territory 129 X 668 Z 1120 radius 3000 map size 200 offset 0,0
    Garland fishing/35 : x 7.69, y 12.21, radius 3000

X/Z sont des pixels de carte (0–2048) : coordonnée de carte = 41 / (taille/100) × pixel / 2048 + 1 = 7,69 et 12,21, comme Garland.
Position dans le monde utilisée par Tensho : (pixel − 1024) / (taille/100) − décalage de la carte. Le lieu retenu est le plus proche du
joueur dans sa zone pendant la pêche (condition « Fishing »).

# 0.1235 — Racing chocobo: ranks, abilities and the game's words (X-204)

Read on 2026-11-13 from the installed game files (game 2026.11.03.0000.0000) with `PROBE_RACECHOCOBO=1` of `tools/ShopCurrencyProbe`, and the
members of `FFXIVClientStructs.FFXIV.Client.Game.RaceChocoboManager` with `tools/ApiProbe`.

## Ranks (`ChocoboRaceRank`, names from `GoldSaucerTextData`)

Rows 2 to 14 carry a name and a rating band: Maiden 1–20 (« Catégorie débutants »), R-40 21–40, R-60 41–60 … R-240 221–240, R-300 241–300
(« Catégorie 300 »); row 1 Training Course (0–0), 15 Open, 16 Chocobo Challenge (0–0). Rows 17 to 31 have overlapping bands and no name:
Tensho keeps only the named rows and takes the first whose band holds the rating.

## Abilities (`ChocoboRaceAbility`)

67 named rows, e.g. 1 Choco Dash / Choco-sprint, 4 Choco Cure / Choco-soin, 7 Choco Esuna / Choco-guérison, with a description: the
chocobo's `AbilityHereditary` and `AbilityLearned` are read as rows of this sheet (0 = none).

## The game's words (`Addon`)

9378 Maximum Speed / Vitesse maximale, 9379 Acceleration / Accélération, 9380 Endurance / Vitalité, 9381 Stamina / Endurance, 9382 Cunning /
Agilité, 9393 Rating / Cote, 9374 Pedigree / Pedigree. No Addon row reads « Hereditary Ability » or « Learned Ability »: those two labels are
Tensho's own.

## The manager

`RaceChocoboManager.State` (Invalid, Requested, Loaded); getters `GetRating`, `GetPedigreeLevel`, `GetAttributesCurrent`, `GetAttributesMaximum`
(each checked resolved before the call); `RequestParameters` (a request to the server) is never called: Tensho reads only after the game loaded
the chocobo. Whether the values match the game's window is to be checked in game.

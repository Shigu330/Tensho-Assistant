# Leve markers on the map (0.652)

P17. Reading of 2026-11-06: leve « Grosse récolte : pierre septentrionale d'ornement » (Leve 1670, miner), Garlemald. `dalamud.log`:

```
11:22:44 Map event marker icon 60492: objective 0, type 0, data 0, tooltip read (length 0, used 54, size 64).
11:25:18 Map event marker icon 60492: objective 530, type 0, data 0, tooltip read radius 35, text "Grosse récolte: pierre septentrionale d'ornement".
```

Report of the user, with captures of both maps: the areas appear once the leve is started, not before and not from a distance. The game draws several dark green circles at the place where Tensho drew blue ones.

## Reading

- Marker type 0, like other events: the type does not tell a leve. Icon 60492 appeared only with this leve, in the logs kept.
- The tooltip is the leve's name, in the game's language, with other spacing than the sheet: « récolte: » in the tooltip, « récolte : » in the sheet.
- Before the start, the game gives no area, so Tensho has none to show. That is the game's behaviour, not a gap.

Tensho marks a marker as a leve by this icon, or by a tooltip naming a row of the Leve sheet, never for a quest marker (type 3).

## Not established

- The icon on other kinds of leve: only one miner leve was read. Their name should match the sheet, which is why the tooltip counts too; not read in game.
- Objective 530: not tied to a sheet.
- The green is matched by eye on a capture.

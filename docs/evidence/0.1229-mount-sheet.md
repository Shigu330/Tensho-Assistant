row 319 (`BGM_EX1_Ride_FlyingMount.scd`) by 90 mounts, row 895 (`BGM_Ride_EX4Common.scd`) by 60, row 121 (`BGM_Ride_CommonMonster.scd`)
by 22, row 62 (`BGM_Ride_Chocobo.scd`) by 7; others belong to one mount only (row 589 `BGM_Ride_Alpha.scd`: Model O; row 805
`BGM_Ride_Fanfes2021.scd`: Lunar Whale). Tensho says « its own riding music » when no other named mount has the same row, else « shared with
N other mounts », and « no riding music » for row 0.

The riding music files are not orchestrion rolls: none of the 886 `OrchestrionPath.File` values is a `BGM_Ride` file, so no roll name is shown.

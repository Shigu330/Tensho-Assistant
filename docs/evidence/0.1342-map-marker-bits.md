# 0.1342 — unlock bits of the fixed map icons (X-351)

Review of the block 0.1318 to 0.1329 (finding I3): on a map the game had not built, Tensho decided a fixed icon with a
`MapMarkerUnlockedBit` (MapMarker sheet) through `UIState.IsUnlockLinkUnlocked`, which was wrong for bit 83 at Mor Dhona
(drawn by the game, read locked; docs/evidence/0.1320-map-marker-unlock.md). Probe in the game on 2026-11-14, plugin 0.1335 to 0.1341,
lines « Map icon unlocks … » of dalamud.log.

## 1. Where the game's list puts a sheet icon (0.1340)

`AgentMap.MapMarkers` positions are (texture pixel − 1024) × 16, whatever the map's size factor. Raw line of 16:05:29, map 14
(Ul'dah, `w1t2/01`, size factor 200, offsets 0, 0): sheet 60441 at pixel 1209, 794 → game 60441 at 2960, −3680; 60983 at
1159, 1197 → 2160, 2768; 60467 at 1254, 1054 → 3680, 480. With this rule 50 of the 50 icons without an unlock bit are found in
the game's list (16:11:08); with the 0.1320 rule « world × 16 » (size factor applied) only 1 of 50. At Mor Dhona (size factor 100)
both rules give the same positions, so the 0.1320 results there stand.

## 2. The array (0.1340 to 0.1342)

The bits are not unlock links: the game keeps an array for these icons, `QuestManager.UnlockedMapMarkers` (FFXIVClientStructs,
64 bytes; the sheet's highest bit is 267). Its content on 11/14 at 16:15:27 (map 14):

`FFFF9FDFFFE1F19439FFF38D54F4D7FFFF96FFF14C14833FFBFFBFFF19F5F86627C0` then zeros.

Read most significant bit first (bit 0 = 0x80 of byte 0), the array gives the game's choice on all ten icons; the unlock-link reading
is wrong on 3, the array read through FFXIVClientStructs' `BitArray` (least significant bit first) on 3. Map 14's three icons 60983
(a blue mask) at 68, 69 and 98 are three places of one marker; only the unlocked one (68) is drawn.

Rule since 0.1342: `MapMarkerUnlock.IsSet(QuestManager.UnlockedMapMarkers, bit)`; a bit past the array is not set (hidden). The
self-check « map icon unlocks » compares it with the game's own list on the map the game has built (player's map or the map its
window shows, the one whose plain icons the list holds) and says « Suspect » on any disagreement.

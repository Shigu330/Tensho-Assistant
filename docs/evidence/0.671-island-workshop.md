## Where each part comes from

| Part | Source | State |
|---|---|---|
| Base value, hours, themes, level | `MJICraftworksObject` | Game data |
| Popularity | `MJICraftworksPopularity[CurrentPopularity]`, then `MJICraftworksPopularityType` | Game data; the row is the FFXIVClientStructs doc |
| Supply | high half of the byte in `SupplyAndDemandShifts` | Row inferred, same table in WorkshopOptimizerPlugin (MIT) and `ban-lee/ffxiv-island-sanctuary` (MIT) |
| Drift of supply: one band per 8 units, in a straight line | WorkshopOptimizerPlugin | Community rule; the sheet's thresholds are 8 apart |
| Workshop | `MJICraftworksRankRatio[BuildingLevel+1]` | **Inferred.** WorkshopOptimizerPlugin uses a flat 1.4 |
| Groove | `ScheduleData.Groove` if the agenda answered, otherwise `CurrentGroove` | The second is marked unverified upstream; a difference is shown |

No game function is called: `RequestDemandFull`, `ScheduleCraft`, `SetDisplayedCycle` and `RequestFavorData` are absent, and a test holds that.

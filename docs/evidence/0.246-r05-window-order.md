# R-05 : ordre des fenêtres Tensho / fenêtres du jeu — faisabilité

Constat (2026-11-01) :
- Dalamud dessine toutes les fenêtres ImGui des plugins en une seule passe, **après** l'interface du jeu. Il n'existe aucune API
  pour intercaler une fenêtre ImGui entre deux fenêtres du jeu : un vrai « ordre d'affichage » comme celui du jeu est impossible.
- Dalamud fournit déjà, par fenêtre (`Window.AllowPinning`, `Window.AllowClickthrough`, `IsPinned`, `IsClickthrough`, présents
  dans `Dalamud.xml` du SDK installé), un menu de barre de titre : épingler, clic traversant, opacité. Tensho ne les désactive pas.

Options possibles :
- A. Retrait automatique : quand la fenêtre du jeu qui a le focus (lue sur le thread du jeu) chevauche une fenêtre Tensho,
  la fenêtre Tensho devient presque transparente et laisse passer les clics, jusqu'à ce que le focus revienne ou que la souris
  la survole. Faisable, réglable (activé ou non, opacité).
- B. Raccourci pour masquer / réafficher toutes les fenêtres Tensho.
- C. Rien de plus : documenter le menu de barre de titre de Dalamud (épingler, clic traversant, opacité).

Décision utilisateur (2026-11-01) : option C retenue, rien à coder. Le menu de barre de titre de Dalamud (épingler, clic traversant, opacité) suffit.

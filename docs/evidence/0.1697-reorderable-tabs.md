# Tabs arranged with the mouse (X-605, 0.1697)

What Dalamud's ImGui allows, checked in the code before writing (no game data involved):

- `ImGuiTabBarFlags.Reorderable` exists in Dalamud.Bindings.ImGui and is already used by the chat window's tabs since 0.1663 (X-687):
  a tab dragged with the mouse moves in the bar, ImGui itself keeps that order while the game runs.
- ImGui gives no public call returning a bar's order. The order shown is read without any internal structure: after each tab item, the
  left edge of the item just drawn (`ImGui.GetItemRectMin().X`); sorting the tabs by that edge gives the order the player sees. A drag is
  under way while a tab item is active and the mouse is dragged (`ImGui.IsItemActive()`, `ImGui.IsMouseDragging`).
- At load the tabs are drawn in the order kept; a new bar (new id) shows the tabs in the order they are drawn, which is how the order kept
  is taken back and how « put back in order » takes effect at once (the bar's id carries a number raised then).

Done in 0.1697: the tabs of every family of pages (the common page header). Not done yet: the pages' own inner tab bars (Storage, Market,
Maps, Free Company…), each written by hand, and the side bar's entries (no ImGui tab bar there: a drag and drop of its own would be needed).

# Onglets rangés à la souris (X-605, 0.1697)

Ce que permet l'ImGui de Dalamud, vérifié dans le code avant d'écrire (aucune donnée du jeu en jeu) :

- `ImGuiTabBarFlags.Reorderable` existe dans Dalamud.Bindings.ImGui et sert déjà aux onglets de la fenêtre de chat depuis 0.1663 (X-687) :
  un onglet tiré à la souris se déplace dans la barre, ImGui garde lui-même cet ordre tant que le jeu tourne.
- ImGui ne donne aucun appel public qui rende l'ordre d'une barre. L'ordre affiché se lit sans structure interne : après chaque onglet, le
  bord gauche de l'élément tout juste dessiné (`ImGui.GetItemRectMin().X`) ; trier les onglets par ce bord donne l'ordre que voit le joueur.
  Un glissement est en cours tant qu'un onglet est actif et que la souris est tirée (`ImGui.IsItemActive()`, `ImGui.IsMouseDragging`).
- Au chargement, les onglets sont dessinés dans l'ordre gardé ; une barre neuve (identifiant neuf) montre les onglets dans l'ordre où ils sont
  dessinés : c'est ainsi que l'ordre gardé revient, et que « remettre dans l'ordre » prend effet tout de suite (l'identifiant de la barre porte
  un numéro alors augmenté).

Fait en 0.1697 : les onglets de chaque famille de pages (l'en-tête commun des pages). Pas encore fait : les barres d'onglets propres aux pages
(Rangements, Marché, Cartes, Compagnie libre…), chacune écrite à la main, et les entrées de la barre de côté (pas de barre d'onglets d'ImGui
là : il faudrait un glisser-déposer à elle).

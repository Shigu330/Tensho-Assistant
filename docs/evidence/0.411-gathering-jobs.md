# 0.411 — R-10 : métier d'un point de récolte (sonde en lecture seule)

Commande : `PROBE_GATHERTYPE=1 dotnet tools/ShopCurrencyProbe/bin/Release/net10.0/ShopCurrencyProbe.dll "<sqpack>"` (feuilles GatheringType
en anglais, GatheringPointBase, ClassJob).

```
TYPE 0 'Mining' bases 430
TYPE 1 'Quarrying' bases 239
TYPE 2 'Logging' bases 332
TYPE 3 'Harvesting' bases 361
TYPE 4 '??' bases 0
TYPE 5 '??' bases 64
JOB 16 'miner'
JOB 17 'botanist'
JOB 18 'fisher'
```

- Mining et Quarrying : mineur (ClassJob 16) ; Logging et Harvesting : botaniste (17) ; lieux de pêche (FishingSpot) : pêcheur (18).
- Type 5 (64 bases, nom illisible) et type 4 (aucune base) : métier inconnu, pas de bouton.
- L'ensemble porté est celui de plus petit numéro pour le métier (RaptureGearsetModule, lu par GameGearsetReader depuis 0.383) ;
  EquipGearset n'est appelé que sur clic, après vérification de son adresse et de l'ensemble (IsValidGearset), comme en 0.385.

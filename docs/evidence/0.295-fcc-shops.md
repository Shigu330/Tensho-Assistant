# Boutiques de compagnie libre (FccShop) (sonde 2026-11-02, lecture seule)

Commande : `PROBE_FCC=1 dotnet run --project tools/ShopCurrencyProbe -c Release -- "<jeu>\game\sqpack"`.

```
FCCSHOP PROPERTIES … Name:ReadOnlySeString, ItemData:Collection (Item, Cost, FCRankRequired)
FCC 2752513 'Échanger des crédits de compagnie (objets)' items 10 :: 10155=Baril de céruleum cost 100 rank 6; 15855=Graines de lavande d'Althyk cost 300 rank 6; …
FCC 2752514 '' items 10 :: 8168=Balai magique cost 1500 rank 6; 12671=Tournesols cost 1800 rank 6; …
NPC 1005632 / 1005639 / 1005646 / 1019100 / 1039486 'officier du logement' -> 2752513 (ENpcData)
NPC 1011274 'pantin aventurier P014A' -> 2752515
```

Lecture : chaque ligne d'`ItemData` = un objet, son prix en crédits de compagnie (`Cost`) et le rang de compagnie requis
(`FCRankRequired`). Les crédits de compagnie ne sont pas un objet : Tensho les nomme par un identifiant réservé (`NpcCost.CompanyCredits`).
Les autres boutiques FccShop sont reliées aux PNJ par les mêmes indirections que les autres boutiques (TopicSelect, PreHandler,
CustomTalk), déjà résolues par le chargeur.

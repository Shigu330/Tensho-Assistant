# Universalis : prix agrégés par lots

Relevé du 2026-11-05 avec curl, `GET https://universalis.app/api/v2/aggregated/Phoenix/{ids}`, objets numérotés à partir de 2.

| Demande | Réponse |
|---|---|
| 100 objets | HTTP 200 : `results` (18 lignes) et `failedItems`, qui ensemble couvrent les 100 |
| 101 objets | HTTP 200 sans erreur : 100 objets seulement ont une réponse, le dernier est ignoré |
| `5,99999999` | `results` donne l'objet 5, `failedItems` donne `[99999999]` |

Une ligne de `results` a la même forme qu'avec un seul objet : `MarketQuote.Parse` la lit déjà par `itemId`.

Conséquence : au plus 100 objets par requête, jamais plus, sinon des objets manquent sans message.

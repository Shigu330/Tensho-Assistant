# Nearest aetheryte wherever coordinates are shown (0.704)

User request, 2026-11-07, after monster loot: « à chaque fois qu'on a des coordonnées ».

Inventory by search for what places a flag or prints coordinates. The shared `PlaceEntries` gets the entry, so `NpcMenu`, `QuestMenu` and `PlaceMenu` all have it. Added on: wiki and Garland monster places, blue magic sources, chat links, hunt train, island animals, bookmarks, the Tensho map's side lists (FATEs, gathering, collectibles, favourites), map search, the Maps page's coordinates, vendor sheets, item source lines, tracker, sightseeing log, gathering and its route.

A test holds it: a page that places a flag must have one of these menus.

## Not covered

- Wiki rows with no coordinates (« Bouquetin triste · Thanalan oriental »): no point to ask from.
- Hover tooltips of items: nothing can be right-clicked there.
- Places the wiki names in a way the game's English place names do not match: no map, so no menu.

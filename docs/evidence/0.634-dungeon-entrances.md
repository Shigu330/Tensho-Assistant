# Dungeon entrances (0.634)

User request, 2026-11-06: a quest that asks for a dungeon should show its entrance, not the dungeon's own map.

## Game data (XIVAPI v2, schema rev e773c41a, French names)

- MapMarker rows with Icon 60414: 87, all named (PlaceNameSubtext).
- TerritoryType rows with TerritoryIntendedUse 3: 122.
- Found: 75 by the place name's row, 27 by the same text, 20 without.
- Without: guildhests (go001 to go014), r1fb, d2d8, w1eh, w1d4_re, d2d1_re, o3d1_re.

Examples: Legs d'Alzadaal, territory 1050, PlaceName 4154, MapMarker 478:37 at (754, 1634). L'Avant-garde, territory 1198, PlaceName 4909, MapMarker 628:0 at (1024, 980).

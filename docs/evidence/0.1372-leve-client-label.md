# X-404 — the « Client: » label of the LeveClient sheet (0.1372)

Probed on 2026-11-15 with `tools/XbmProbe` (game 2026.11.03.0000.0000, Steam client), sheet `LeveClient`, 301 rows, one string column; 282 rows
hold a name. Counted: the text before the first colon (`:` or the full-width `：`).

| Language | Rows with a name | Text before the first colon |
|---|---|---|
| English | 282 | `Client:` on 282 (row 1: « Client: 2nd Levy Infantry, Yellowjacket Sergeant Sylskaetsyn ») |
| French | 282 | `Client :` with a no-break space, on 282 (row 1: « Client : Sergent-major Sylskaetsyn ») |
| German | 282 | `Auftraggeber:` on 242, `Auftraggeberin:` on 40 (row 1: « Auftraggeber: Gelbjackengefreiter Sylskaetsyn ») |
| Japanese | 282 | no common label: 19 names without a colon, the most frequent text before one on 7 rows (« アマジナ鉱山社： », a company) |

The plugin read `LeveClient.Name` as it is and wrote `Client : {name}` in the Guildleves tooltip, so the label showed twice; the Client column and
filter repeated it on each row. Since 0.1372 the label is found from the sheet itself (`LeveCatalog.ClientLabels`: a short text up to the first
colon, without a comma, starting at least two names and a tenth of them, the labels kept starting together at least four names in five) and taken off once
(`LeveCatalog.WithoutClientLabel`); in Japanese nothing is taken off.

The context menu entry `Leves.AetheryteClient` uses the leve's `LevelLevemete` row: the NPC the leve is taken from or delivered to (a levemete, a
Grand Company sergeant or a delivery NPC, depending on the leve), not the client named by `LeveClient`. Its label now says « the leve's NPC » /
« PNJ du mandat ».

Command (from `C:\Plugins-ff14`, with a .NET 10 SDK):

```bash
dotnet run --project tools/XbmProbe -c Release -- "C:\Program Files (x86)\Steam\steamapps\common\FINAL FANTASY XIV Online\game\sqpack" French LeveClient
```

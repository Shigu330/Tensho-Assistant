# 0.387 — grimoire du mage bleu : nom du sort envoyé au wiki

Signalement de l'utilisateur (2026-11-03) : la fiche d'un sort (« 28 · Mauvaise haleine ») dit toujours que le wiki ne liste aucun
monstre.

Relevés en lecture seule (2026-11-03) :

- `api.php?action=parse&…&page=Bad_Breath` : page « Bad Breath » (révision 1537705), tableau `item sortable stdt__table_v2`,
  en-têtes Enemy | Level | Location, 19 lignes (Ark Morbol, Capricious Cassie, … Voluptuous Vivian). Les règles de
  `WikiMonsterParser` lisent bien ces 19 lignes.
- `api.php?action=parse&…&page=Mauvaise_haleine` : `{"error":{"code":"missingtitle",…}}`.

Cause : le nom anglais était lu par `AozAction` (feuille anglaise) puis le lien `Action` de la ligne, résolu dans la langue du client.
Le wiki recevait le nom français, répondait « page inexistante », et Tensho affichait « aucun monstre ». Le nom vient maintenant de la
feuille `Action` anglaise, par numéro de ligne.

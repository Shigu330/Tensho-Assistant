# 0.478 : seuils d'un collectionnable au nom long (2026-11-04)

Rapport en jeu (capture de l'utilisateur) : le panneau Collectionnable affichait « Minerai de durium noble c... » et « Aucun seuil de remise connu ».

Relevé par XIVAPI v2 (fichiers du jeu, version `0874aee069e1e7c4`) :

- `Item` 36291 : « Minerai de durium noble collectionnable » (`IsCollectable` vrai).
- `CollectablesShopItem` 31/22, `Item` 36291, niveaux 80 à 81, `CollectablesShopRefine` 124 : seuils **400 / 700 / 1000**.

Capture de l'échange d'objets collectionnables en jeu (utilisateur, 2026-11-04) : « Minerai de durium noble collecti... », Nv 81, « 400 ou plus », 3 assignats. Même seuil bas, et le jeu coupe ce nom là aussi.

La règle existe. Le texte de la fenêtre du jeu (`AddonGatheringMasterpiece.ItemName`) est coupé avec « ... » quand le nom est long, et Tensho cherchait le nom exact.

Correction : un nom coupé est cherché par son début, et n'est accepté que s'il désigne un seul objet. Plusieurs candidats donnent « aucun seuil », sans deviner.

`AddonGatheringMasterpiece` n'a pas de champ nommé pour la collectabilité en cours (FFXIVClientStructs, lu le 2026-11-04). Elle reste à trouver dans les valeurs brutes de la fenêtre.

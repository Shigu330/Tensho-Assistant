## The game's own list

AgentMap.MapMarkers (what the game's map draws) gives positions as world × 16: Mor Dhona's aetheryte, sheet 108.3 at pixel 1064, 356,
is listed « at 640,-10688 » (dalamud.log of 11/14 11:14:28): (1064 − 1024) × 16 = 640, (356 − 1024) × 16 = −10688.

## Rule and check

- A fixed icon with an unlock bit is drawn only when the game says the bit is unlocked (UIState.IsUnlockLinkUnlocked); unknown hides it.
- The self-check « map icon unlocks » compares, for the map the game has built, each icon with an unlock bit: listed by the game or not,
  against its bit read unlocked; « DISAGREE » in the log when they differ. The reading of the bit through IsUnlockLinkUnlocked is the
  hypothesis that this check proves or refutes in the game (line « Map icon unlocks on map … » of dalamud.log).

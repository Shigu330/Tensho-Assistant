X-265, user request of 2026-11-13: sort the allied societies by kind (combat, crafting, gathering).

## Read on 2026-11-14 (`tools/AlliedKindProbe`, French client, game 2026.11.03)

(32 gatherers, 33 crafters, any other non-zero row combat); the kind of a quest category is the union of the kinds of the classes it allows.

# Peuples alliés par genre (0.1306)

X-265, demande de l'utilisateur du 13/11/2026 : trier les peuples alliés par genre (combat, artisanat, récolte).

## Lu le 14/11/2026 (`tools/AlliedKindProbe`, client français, jeu 2026.11.03)

Chaque quête d'un peuple (`Quest.BeastTribe`) porte une `ClassJobCategory0`. Le genre d'une classe est sa propre `ClassJob.ClassJobCategory`
(32 récolteurs, 33 artisans, toute autre ligne non nulle combat) ; le genre d'une catégorie de quête est l'union des genres des classes
qu'elle permet. `ClassJobCategory` est lue brute : colonne 0 le nom, colonne i + 1 la ligne i de `ClassJob`. Vérifié sur toutes les
catégories qui portent le nom d'une classe (« BOT » permet la classe d'abréviation « BOT », et elle seule) : 43 catégories, 43 OK. Les noms
des genres sont ceux des `ClassJobCategory` 34, 33 et 32, dans la langue du client.

Résultat : 14 peuples de combat (catégorie 142), 5 d'artisanat (33), 3 de récolte (32), et les Namazu, artisanat et récolte (35) : ils
sont montrés sous les deux genres.

# 0.1655: the cities for the chat window's contexts (X-447 B13)

> *Traduction française plus bas.*

## Question

The chat window's profiles by context (X-447 B13, D-198) change its look « in a city ». What tells, from the game's own data, that the
zone the player is in is a city?

## Reading

`tools/XbmProbe`, French client, 20/11/2026, sheet `TerritoryType` (1290 rows, 46 columns), column 10 `TerritoryIntendedUse` (counted as
in docs/evidence/0.975-field-zones.md). Every row whose use is 0 and that has a name (19 rows):

128 s1t1, 129 s1t2 (Limsa Lominsa), 130 w1t1, 131 w1t2 (Ul'dah), 132 f1t1, 133 f1t2 (Gridania), 136 s1h1_test (a test map, never
entered), 418 r2t1, 419 r2t2 (Ishgard), 478 d2t1 (Idyllshire), 628 e3t1 (Kugane), 635 g3t1 (Rhalgr's Reach), 759 e3ec (the Doman
Enclave), 819 n4t1 (the Crystarium), 820 n4t2 (Eulmore), 962 k5t1 (Old Sharlayan), 963 m5t1 (Radz-at-Han), 1185 y6t1 (Tuliyollal),
1186 x6t1 (Solution Nine).

The other uses are not cities: the inn rooms are 2 (177 s1ti, the Mizzenmast), the housing districts 13 (339 s1h1, Mist), the open zones 1.

## Use

`ChatContexts.TownUse` = 0; the plugin reads the zone's row once per zone (Plugin.cs, `InTownNow`); a row it cannot read is no city.

# 0.1655 : les villes des contextes de la fenêtre de chat (X-447 B13)

## Question

Les profils par contexte de la fenêtre de chat (X-447 B13, D-198) changent son aspect « en ville ». Qu'est-ce qui dit, dans les données du
jeu lui-même, que la zone du joueur est une ville ?

## Relevé

`tools/XbmProbe`, client français, 20/11/2026, feuille `TerritoryType` (1290 lignes, 46 colonnes), colonne 10 `TerritoryIntendedUse`
(comptée comme dans docs/evidence/0.975-field-zones.md). Toutes les lignes d'usage 0 qui ont un nom (19 lignes) :

128 s1t1, 129 s1t2 (Limsa Lominsa), 130 w1t1, 131 w1t2 (Ul'dah), 132 f1t1, 133 f1t2 (Gridania), 136 s1h1_test (une carte d'essai, où
l'on n'entre jamais), 418 r2t1, 419 r2t2 (Ishgard), 478 d2t1 (Idyllée), 628 e3t1 (Kugane), 635 g3t1 (Rhalgr's Reach), 759 e3ec (l'Enclave
doméenne), 819 n4t1 (Cristarium), 820 n4t2 (Eulmore), 962 k5t1 (Vieille Sharlayan), 963 m5t1 (Radz-at-Han), 1185 y6t1 (Tuliyollal),
1186 x6t1 (Solution Neuf).

Les autres usages ne sont pas des villes : les chambres d'auberge sont 2 (177 s1ti, l'Hôtel du Mât d'artimon), les quartiers résidentiels
13 (339 s1h1, Brumée), les zones ouvertes 1.

## Usage

`ChatContexts.TownUse` = 0 ; le plugin lit la ligne de la zone une fois par zone (Plugin.cs, `InTownNow`) ; une ligne illisible n'est pas une
ville.

# 0.1677: the game's own names for the pages and tabs (X-601)

English first, then French.

## English

The side bar is reduced to pages that group their tools as tabs (X-601). Each page, tab and category takes the game's own name in the
client's language when the game has one. The names were read from the installed client's sheets (game 2026.11.03.0000.0000) with
`tools/HelpTextProbe`, mode `names`: every text of every sheet that **is** the name asked (not a text that merely holds it), printed with the
same cell in French, English, German and Japanese.

```powershell
dotnet run --project tools/HelpTextProbe -c Release -- names "<sqpack>" French all "Personnage" "Bestiaire" "Armes antiques"
dotnet run --project tools/HelpTextProbe -c Release -- names "<sqpack>" French MainCommand,ContentType,HowToCategory "*"
```

A name used in a version is checked by a test against the two language files (`PageFamilies1677Tests.GameNames`).

### Names the game does not have (Tensho's own name kept)

No text of any sheet is one of these, in French or in English (probe answer « NO TEXT IS … »), or the game uses the word for something else:

- Home (Accueil), My tools (Mes outils), Wishlist (Souhaits), Lexicon (Lexique), Discoveries (Découvertes), Reminders (Rappels),
  Diagnostics, Storage (Rangements: the game names each place, « Inventaire », « Arsenal », « Sacoche chocobo », never all of them).
- Collections: the game's « Collection » (MainCommand 87, English) is another window (« Objets précieux »).
- World (Monde): the grouping is Tensho's (map, weather, FATEs, shops, loot, discoveries); the word exists (Addon 1292) but names the
  game server there.
- Weather (Météo): French « Météo » is Addon 9383 (English « Preferred Weather ») and English « Weather » is Addon 8555 (French
  « Temps »): no row gives both words, both kept.
- Tracking (Suivi), Alarms (Alarmes): the game's own alarm is « Alerte » / « Alarm » (ExtraCommand 3) and its timers window is
  « Calendrier » / « Timers » (MainCommand 5); Tensho's names kept until the user chooses.
- Credits (Crédits): Addon 3465 has the word, for a currency.
- Special deliveries (Livraisons spéciales), Eureka and Bozja, Duty loot, Monster loot: made of the game's words, no row is the whole name.
- The tabs of Tensho's own tools in crafting and gathering (simulation, presets, live synthesis, GP planning).

le jeu lui donne dans la langue du client, quand le jeu en a un. Les noms ont été lus dans les feuilles du client installé (jeu
2026.11.03.0000.0000) avec `tools/HelpTextProbe`, mode `names` : chaque texte de chaque feuille qui **est** le nom demandé (pas un texte qui
le contient seulement), avec la même cellule en français, anglais, allemand et japonais (commandes ci-dessus).

Un nom utilisé dans une version est vérifié par un test contre les deux fichiers de langue (`PageFamilies1677Tests.GameNames`).

### Noms que le jeu n'a pas (nom propre à Tensho gardé)

Aucun texte d'aucune feuille n'est l'un de ces noms, en français ou en anglais (réponse de la sonde « NO TEXT IS … »), ou le jeu emploie
le mot pour autre chose :

- Accueil, Mes outils, Souhaits, Lexique, Découvertes, Rappels, Diagnostics, Rangements (le jeu nomme chaque endroit, « Inventaire »,
  « Arsenal », « Sacoche chocobo », jamais l'ensemble).
- Collections : le « Collection » du jeu (MainCommand 87, en anglais) est une autre fenêtre (« Objets précieux »).
- Monde : le regroupement est celui de Tensho (carte, météo, ALÉA, échoppes, butin, découvertes) ; le mot existe (Addon 1292) mais y nomme
  le serveur de jeu.
- Météo : « Météo » est Addon 9383 (anglais « Preferred Weather ») et « Weather » est Addon 8555 (français « Temps ») : aucune ligne ne
  donne les deux mots, les deux sont gardés.
- Suivi, Alarmes : l'alarme du jeu s'appelle « Alerte » / « Alarm » (ExtraCommand 3) et sa fenêtre des minuteurs « Calendrier » / « Timers »
  (MainCommand 5) ; les noms de Tensho restent jusqu'au choix de l'utilisateur.
- Crédits : Addon 3465 a le mot, pour une monnaie.
- Livraisons spéciales, Eurêka et Bozja, Butin des missions, Butin des monstres : faits de mots du jeu, aucune ligne n'est le nom entier.
- Les onglets des outils propres à Tensho dans l'artisanat et la récolte (simulation, préréglages, synthèse en cours, planification des PR).

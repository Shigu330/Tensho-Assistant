# FATEs of the open zones (0.721)

Follows W-14: `docs/evidence/0.717-eureka-bozja.md` found that `Fate.Location` is an instance id of the zone's layout. Nothing comes from a site or a plugin.

`tools/FateRangeProbe` with `all`, French client, 2026-11-07: 1701 `Fate` rows have a location, 1585 are placed by some layout, in 272 territories. Most of these territories are quest and instance copies of the open zones (intended use 9, 29…) and repeat their layouts. Intended use 1 keeps 47 zones and 1127 rows, of which 1123 have a name: the page shows those (read inside the game by the self-check of 0.722); the only zone of that use with none is the Wolves' Den Pier.

Sample: Noscea centrale, 28; Thanalan méridional, 34; Steppe d'Azim, 44; Yak T'el, 16.

## Inferred, to compare in the game

1. The position is the centre of the range in the layout, as for Eureka.
2. A FATE listed may no longer run, or run only after an event: the sheet does not say so. The page says « in the files », not « running ».

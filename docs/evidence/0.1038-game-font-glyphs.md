# Game font glyphs (0.1038)

Question: which characters of Tensho's texts the game font cannot draw. Night test T-0.502-1 (2026-11-10) showed « ↺ » of the
Settings help as « = »: ImGui draws Dalamud's fallback mark (U+3013 « 〓 ») for a character the font lacks.

Fonts: Dalamud's default font and Tensho's body font are the game's AXIS family; Tensho's title and section fonts are TrumpGothic by default.

Method: `dotnet run --project tools/UldProbe -c Release -- <sqpack> --fdt common/font/<name>.fdt` (game 2026.11.03.0000.0000, 2026-11-11).
It reads the font table of the `.fdt` file (header `fcsv`, table `fthd` at the offset in bytes 8–11, glyph count at table + 4, one
16-byte entry per glyph from table + 32, character as packed UTF-8 in the first 4 bytes) and prints one code point per glyph.

Result:

| Font | Glyphs |
|---|---|
| AXIS_12, AXIS_14, AXIS_18 | 7 594 each: printable ASCII, all of Latin-1 (U+00A0–U+00FF), kana, 6 357 CJK ideographs, and among the symbols Tensho uses: Œ œ Σ – — ‘ ’ “ ” … › ‹ ← ↑ → ↓ ≠ ≤ ≥ ● ○ ◆ ★ － |
| TrumpGothic_23 | 211 (Latin letters with French accents included: every sidebar category title in English and French is covered) |
| Jupiter_16 | 207 |
| MiedingerMid_12 | 197 |

Missing from AXIS and found in Tensho's texts before 0.1038: ↺ (U+21BA), ↔ (U+2194), ↘ (U+2198), ↙ (U+2199), ≈ (U+2248),
⌈ ⌉ ⌊ ⌋ (U+2308–U+230B), ⏰ (U+23F0), ⚠ (U+26A0), 🔔 (U+1F514), and ↳ (U+21B3) in the game's item context menu. 0.1038 replaces
them by words, « ~ », « floor( » / « ceil( », « → » or an icon of the icon font; ⏰ and 🔔 stay in the Discord alarm message and its
test, which are sent to Discord and drawn there. `tests/TenshoAssistant.Tests/FontGlyphs1038Tests.cs` holds the allowed set.

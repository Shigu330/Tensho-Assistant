## Limites

Relevés sur un seul objet. Une case cochée ou une Inspection active se retire par la largeur de Sélection instinctive (50 moins 49 = gain simple). Le plan est refait à chaque tour avec les valeurs lues. Si une valeur manque ou change de type, aucun plan n'est proposé.

Non modélisé : Toucher d'amorçage. Inspection rigoureuse suppose que les gains affichés la contiennent quand elle est active : à confirmer par un relevé.

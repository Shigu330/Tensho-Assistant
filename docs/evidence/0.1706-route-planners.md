# The two route planners, compared and merged (X-604, 0.1706)

The user's request of 18/11: airships and submarines each had their own route planner (Free Company › Best routes for submarines, Free
Company › Airship sectors for airships); keep the best of both in one. Read in the code on 21/11/2026: `MainWindow.RoutePlanner.cs` and
`FreeCompany/VoyagePlanner.cs` (submarines), `MainWindow.AirshipPlanner.cs`, `FreeCompany/AirshipPlanner.cs` and `FreeCompany/AirshipSectors.cs`
(airships).

| Feature | Submarines | Airships |
|---|---|---|
| Vessel read in the workshop, or manual input | yes | yes (same model, a second combo) |
| Planned build (Builds tab) gives rank, speed, range | yes | no |
| Map | chosen among the submarine maps | one map, no choice |
| Rank, speed, range editable | the three | speed and range (rank: the vessel's, 0 = all) |
| Goals | value per voyage, value per day, experience | experience per day or per voyage, shortest, an item's loot, a sector to unlock |
| Loot value | community averages × NPC or market price (Universalis, 32 items per click), surveillance band | unknown (no quantity or rate published) |
| Unlocked sectors only | yes (read in the company workshop) | no (not read for airships) |
| Target « loot » (an item → the sectors where it drops) | no | yes (list with a search) |
| Target « unlock » (a sector → its chain) | shown only (0.1703), routes not filtered | routes filtered (through the sector that unlocks it), chain shown |
| Sectors chosen by hand (best order, distance, duration, experience, tanks) | no | yes |
| Fleet (each vessel's own best route) | no | yes |
| Leg times | formulas on positions (original code) | the game's functions on the framework thread, « not confirmed in game » shown |
| Results | 25 best, loot tooltip, « ≥ » when a price is missing | 15 best, « ≥ » when an experience is unknown |
| To the Builds tab | « Build » button per route | no |
| Search on a worker, cancelled when an input changes | yes | yes (twice: routes and fleet) |

Code written twice: the vessel combo and the rank, speed and range fields; the search on a worker (key, cancellation source, task, reading
the result: three copies); the unlock chain (`AirshipSectors.UnlockPath`, `SubmarineUnlocks.Path`).

The merge, in versions: (1, 0.1706) one planner in the Best routes tab with the kind at its top; the common part (vessel, planned build for both
kinds, rank, speed and range) and one search class (`PlannerSearch`, the fleet's search now also stops with the window); the Airship sectors tab
keeps its table, its « Choose » column, and a button that opens the planner on airships. (2) Targets and sectors chosen by hand for both kinds.
(3) The fleet for both kinds. What the data does not allow stays said: the loot value of airships (no published quantities), unlocked
airship sectors (not read in the workshop), the route check of the Builds tab (submarines only).

Tests kept (none removed): Routes335Tests, AirshipTests, AirshipTargets1243Tests, AirshipFleet1248Tests, VoyageItemSources1568Tests,
SourceUses1044Tests, SubmarineUnlock1703Tests; the lines that named the old fields follow the new names.

# Les deux planificateurs de trajets, comparés et réunis (X-604, 0.1706)

Demande de l'utilisateur du 18/11 : les aéronefs et les sous-marins avaient chacun leur planificateur de trajets (Compagnie libre › Meilleurs
trajets pour les sous-marins, Compagnie libre › Secteurs d'aéronef pour les aéronefs) ; garder le meilleur des deux en un seul. Lu dans le code
le 21/11/2026 : `MainWindow.RoutePlanner.cs` et `FreeCompany/VoyagePlanner.cs` (sous-marins), `MainWindow.AirshipPlanner.cs`,
`FreeCompany/AirshipPlanner.cs` et `FreeCompany/AirshipSectors.cs` (aéronefs).

| Fonction | Sous-marins | Aéronefs |
|---|---|---|
| Vaisseau lu à l'atelier, ou saisie manuelle | oui | oui (même modèle, une deuxième liste) |
| Montage prévu (onglet Montages) qui donne rang, vitesse, autonomie | oui | non |
| Carte | choisie parmi les cartes des sous-marins | une seule carte, pas de choix |
| Rang, vitesse, autonomie modifiables | les trois | vitesse et autonomie (rang : celui du vaisseau, 0 = tous) |
| Buts | valeur par expédition, valeur par jour, expérience | expérience par jour ou par expédition, plus court, butin d'un objet, secteur à débloquer |
| Valeur du butin | moyennes de la communauté × prix PNJ ou du marché (Universalis, 32 objets par clic), tranche de surveillance | inconnue (aucune quantité ni aucun taux publiés) |
| Secteurs débloqués seulement | oui (lus à l'atelier de la compagnie) | non (pas lus pour les aéronefs) |
| Cible « butin » (un objet → les secteurs où il tombe) | non | oui (liste avec recherche) |
| Cible « déblocage » (un secteur → sa chaîne) | affichée seulement (0.1703), trajets non filtrés | trajets filtrés (par le secteur qui le débloque), chaîne affichée |
| Secteurs choisis à la main (meilleur ordre, distance, durée, expérience, barils) | non | oui |
| Flotte (meilleur trajet de chaque vaisseau) | non | oui |
| Durée des étapes | formules sur les positions (code original) | fonctions du jeu sur le fil du jeu, « non confirmé en jeu » affiché |
| Résultats | 25 meilleurs, info-bulle du butin, « ≥ » quand un prix manque | 15 meilleurs, « ≥ » quand une expérience est inconnue |
| Vers l'onglet Montages | bouton « Monter » par trajet | non |
| Recherche sur un fil, annulée quand une entrée change | oui | oui (deux fois : trajets et flotte) |

Code écrit deux fois : la liste des vaisseaux et les champs rang, vitesse et autonomie ; la recherche sur un fil (clé, source d'annulation,
tâche, lecture du résultat : trois copies) ; la chaîne de déblocage (`AirshipSectors.UnlockPath`, `SubmarineUnlocks.Path`).

La réunion, par versions : (1, 0.1706) un seul planificateur dans l'onglet Meilleurs trajets, le genre en tête ; la partie commune (vaisseau,
montage prévu pour les deux genres, rang, vitesse et autonomie) et une seule classe de recherche (`PlannerSearch`, la recherche de la flotte
s'arrête aussi avec la fenêtre) ; l'onglet Secteurs d'aéronef garde son tableau, sa colonne « Choisir » et un bouton qui ouvre le planificateur
sur les aéronefs. (2) Cibles et secteurs choisis à la main pour les deux genres. (3) La flotte pour les deux genres. Ce que les données ne
permettent pas reste dit : la valeur du butin des aéronefs (aucune quantité publiée), les secteurs d'aéronef débloqués (pas lus à l'atelier),
le contrôle d'un trajet de l'onglet Montages (sous-marins seulement).

Tests gardés (aucun retiré) : Routes335Tests, AirshipTests, AirshipTargets1243Tests, AirshipFleet1248Tests, VoyageItemSources1568Tests,
SourceUses1044Tests, SubmarineUnlock1703Tests ; les lignes qui nommaient les anciens champs suivent les nouveaux noms.

Icônes de carte = MapIconAvailable / MapIconInvalid + 1..IconRange (les états d'une quête : nouvelle, en cours, terminée…), absentes de
MapSymbol. Le sens exact de chaque variante n'est pas dans la feuille : les réglages montrent l'image du jeu et « variante n ».
Noms de catégorie donnés seulement pour les séries connues (3 = 71001… épopée, 1 = annexe, 8/10 = déblocage bleu) ; les autres « Quête (type n) ».

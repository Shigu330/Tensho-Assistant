# Épopée d'ARR : quêtes propres à chaque cité de départ (sonde 2026-11-02, lecture seule)

Commande : `PROBE_STARTCITY=1 dotnet run --project tools/ShopCurrencyProbe -c Release -- "<jeu>\game\sqpack"`.
Méthode : quêtes du genre 1 (« Chroniques de la 7e ère ombrale ») ; racines = celles sans quête précédente du même genre ; pour
chaque quête, l'ensemble des racines auxquelles remonte sa chaîne `PreviousQuest`.

```
ROOT 65621 / 65659 / 65660 'Une visite s'impose' place 39 'Gridania'
ROOT 65644 / 65645         'Une visite s'impose' place 27 'Limsa Lominsa'
ROOT 66104 / 66105 / 66106 'Une visite s'impose' place 51 'Ul'dah'
ROOTSET [Gridania 65621+65659+65660]          quests 21  (Visite au Bannock, Le fantôme de la prison…)
ROOTSET [Limsa 65644+65645]                   quests 21  (Le jour de l'Ascenciel, Bombo échappé…)
ROOTSET [Ul'dah 66104+66105+66106]            quests 23  (Dites-le avec une citrouille, Manque de veine…)
ROOTSET [les 8 racines]                       quests 141 (Les tréfonds de Sastasha, L'épreuve des flammes…) = tronc commun
ROOTSET [Gridania + Limsa]                    quests 1   (L'appel de la mer) = traité comme commun
+ les 8 racines elles-mêmes (une quête chacune)
```

Règle Tensho (0.285) : une quête dont toutes les racines sont dans une seule cité (lieu de la racine) appartient à cette cité. La
cité du personnage est celle dont une quête est confirmée terminée ; les quêtes des deux autres cités sont écartées des listes
(option pour les afficher) et des pourcentages.

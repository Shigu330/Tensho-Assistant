- `IKDRouteTable` : 144 lignes ; `Route` = trajet depuis Limsa Lominsa (lignes IKDRoute 1 à 12), `Unknown0` = trajet depuis Kugane
  (13 à 21). Début de boucle : 7/19, 10/13, 1/19, 4/16, 8/20, 11/14, 2/20, 5/17, 9/21, 12/15, 3/21, 6/18, 10/13…

  trajet porte le nom du moment de sa dernière escale.

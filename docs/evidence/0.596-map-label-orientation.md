# MapMarker.SubtextOrientation: where the game writes a name beside its icon

Date: 2026-11-05. Probe in read-only mode on XIVAPI v2 (`https://v2.xivapi.com/api/sheet/MapMarker`, game data version `0874aee069e1e7c4`): 8,674 rows, fields X, Y, Icon, SubtextOrientation, PlaceNameSubtext.Name.

No source found states the meaning: FFXIVClientStructs only names the field, and the open projects read for this either copy the value or leave it unused. It is measured here. **Inferred from the data, not stated by the game; to confirm in game.**

## Method

Two labelled icons close together on the same map have their names pointing away from each other, or the names would overlap. So for pairs of neighbours: the value carried by the left, right, upper and lower icon.

| Pairs (same map) | Left icon 1, right icon 2 | Left icon 2, right icon 1 |
|---|---|---|
| dy < 20, dx < 80 | 20 | 1 |
| dy < 20, dx < 120 | 27 | 1 |
| dy < 20, dx < 180 | 43 | 1 |

| Pairs (same map) | Upper icon 4, lower icon 3 | Upper icon 3, lower icon 4 |
|---|---|---|
| dx < 40, dy < 40 | 21 | 0 |
| dx < 40, dy < 60 | 38 | 0 |
| dx < 40, dy < 90 | 51 | 1 |

Example (map range 3): `Figaga's Gift` at 1010,1205 has 1 and `The Roost` at 1078,1222 has 2.

## Result

| Value | Name written | Labelled icons |
|---|---|---|
| 1 | left of the icon | 475 |

| 4 | above the icon | 1,573 |
| other (0, 5 to 11) | not established: right of the icon in Tensho | 87 |

The position of icons near the map's edges (mean Y, for example) does not settle left and right, and is weaker than the pairs: it is not used.

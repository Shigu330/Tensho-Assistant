(`/api/v2/data-centers`), read once per session. The game has it: sheet `WorldDCGroupType`, column `Region` (a `WorldRegionGroup` row).

## Universalis' answer (`GET /api/v2/data-centers`, 2026-11-08, region per data centre)

Elemental, Gaia, Mana, Meteor: Japan. Aether, Primal, Crystal, Dynamis: North-America. Chaos, Light: Europe. Materia: Oceania.
陆行鸟, 莫古力, 猫小胖, 豆豆柴: 中国. 한국: 한국. 陸行鳥: 繁中服. (Shadow and the cloud data centre are not listed.)

Shadow (region 3) is named Europe from the game sheet; Universalis does not list it yet.

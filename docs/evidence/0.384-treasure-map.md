# 0.384 — carte au trésor déchiffrée (M-14)

Sondes `tools/ApiProbe` (métadonnées seulement, 2026-11-03) :

- `EventItemManager` : `GetTreasureHuntRank()` (UInt32) et `GetTreasureSpotSubKey()` (UInt16), toutes deux dans
  `EventItemManager.MemberFunctionPointers` (adresses vérifiées avant l'appel).
- Feuille `TreasureSpot` (sous-lignes) : `Location` (→ `Level`), `MapOffsetX`, `MapOffsetY`.
- Feuille `TreasureHuntRank` : `ItemName` (→ `Item`), `KeyItemName`, `InstanceMap`, `MaxPartySize`.
- Feuille `Level` : `X`, `Y`, `Z`, `Map`, `Territory`.

**À confirmer en jeu** : la ligne `TreasureSpot` est le rang et la sous-ligne la sous-clé (choix de lecture) ; `MapOffsetX/Y` ne
sont pas utilisés (la position vient de `Level`).

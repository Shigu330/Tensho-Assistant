# Instances with the game's own map (0.1308)

X-262, user's choice of 2026-11-13 after the Palace of the Dead 1-10: deep dungeons are no longer cut (DEC-038 completed), but Tensho's
map gives way to the game's in an instance whose map the game draws itself, found in the sheets rather than listed.

## Read on 2026-11-14 (French client, game 2026.11.03; a throwaway Lumina probe, its code summed up here)

Rule: the territory of a `ContentFinderCondition` row that no map of the sheets covers: `TerritoryType.Map` is 0 and no `Map` row has
that `TerritoryType`. Every deep dungeon floor set is in that case (`TerritoryIntendedUse` 31, `Map` 0, no `Map` row: 561 to 565, 593 to
607, 1099 to 1108, 1281 to 1290; Heaven-on-High's floors are reached through `ContentFinderCondition` only). The duties found, by content type:


nothing to show there either.

# Instances à carte propre (0.1308)

X-262, choix de l'utilisateur du 13/11/2026 après le Palais des morts 1-10 : les donjons profonds ne sont plus coupés (DEC-038 complétée),
mais la carte de Tensho laisse la place à celle du jeu dans une instance dont le jeu dessine lui-même la carte, repérée par les feuilles
plutôt que listée.

## Lu le 14/11/2026 (client français, jeu 2026.11.03 ; sonde Lumina jetable, son code résumé ici)

Règle : le territoire d'une ligne `ContentFinderCondition` qu'aucune carte des feuilles ne couvre : `TerritoryType.Map` vaut 0 et aucune
ligne `Map` n'a ce `TerritoryType`. Tous les donjons profonds sont dans ce cas (`TerritoryIntendedUse` 31, `Map` 0, aucune ligne `Map` :
561 à 565, 593 à 607, 1099 à 1108, 1281 à 1290 ; les étages du Pilier des cieux ne sont reliés que par `ContentFinderCondition`). Les
contenus trouvés, par type : 46 jeux du Gold Saucer (type 19), 50 donjons profonds (type 21), l'épreuve du Diadème (630, type 23), le
Verset final (1311, 1333, type 39), Les Nuées de Brandons (extrême) (912, type 4).

Les jeux du Gold Saucer comprennent Lord of Verminion, coupé de toute façon (DEC-038) ; les autres n'ont aucune carte dans les feuilles :
la carte de Tensho n'avait rien à y montrer non plus.

# 0.332 — Cadre des fenêtres du jeu (ULD) : sonde

Sonde en lecture seule `tools/UldProbe` (Lumina, fichiers du jeu installés, client Steam), le 2026-11-02 :

```
dotnet run --project tools/UldProbe -- "<sqpack>" Inventory RecipeNoteBook
dotnet run --project tools/UldProbe -- "<sqpack>" --tex WindowA_BgNormal_Corner WindowA_BgNormal_H WindowA_BgNormal_V WindowA_BgNormal_HV
dotnet run --project tools/UldProbe -- "<sqpack>" --parts Inventory WindowA_BgNormal
```

## Découpage déclaré par Inventory.uld (liste 2, cadre normal)

```
PART list 2 ui/uld/WindowA_BgNormal_Corner.tex U=0 V=0 W=16 H=64
PART list 2 ui/uld/WindowA_BgNormal_H.tex U=0 V=0 W=32 H=64
PART list 2 ui/uld/WindowA_BgNormal_Corner.tex U=16 V=0 W=16 H=64
PART list 2 ui/uld/WindowA_BgNormal_V.tex U=0 V=0 W=16 H=32
PART list 2 ui/uld/WindowA_BgNormal_HV.tex U=0 V=0 W=32 H=32
PART list 2 ui/uld/WindowA_BgNormal_V.tex U=16 V=0 W=16 H=32
PART list 2 ui/uld/WindowA_BgNormal_Corner.tex U=0 V=64 W=16 H=32
PART list 2 ui/uld/WindowA_BgNormal_H.tex U=0 V=64 W=32 H=32
PART list 2 ui/uld/WindowA_BgNormal_Corner.tex U=16 V=64 W=16 H=32
```

Lecture : bande haute 64 px (coins U 0 et U 16, largeur 16 ; bord H), côtés 16 px (V), centre HV, bande basse 32 px (V 64 des coins et de H).
Les textures _hr1 font le double ; le plugin garde le découpage en fractions de chaque texture (src/TenshoAssistant/UI/Components/GameFrame.cs).

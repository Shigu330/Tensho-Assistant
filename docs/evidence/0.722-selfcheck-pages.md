# Self-check of the pages coded without the game (0.722)

The plugin reloads in the running game at each build. In developer mode, or on request, the self-check now also runs what opening these pages runs, once per load, and writes the counts to `dalamud.log`: Eureka and Bozja, FATEs, deep dungeons, lexicon, relics, allied societies, Grand Companies, custom deliveries, Masked Carnivale.

Sheets are read off the frame, the game's data on the framework thread: the same delegates as the pages. Only the numbers are kept, so the lexicon's words do not stay in memory because of this.

This proves the reads run and what they count. It does not prove that a page draws well, nor that what it says matches the game's windows: that stays in `docs/project/TESTING.md`.

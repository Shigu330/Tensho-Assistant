# 0.904 — X-76 step 1: dead code and unused language keys removed

## How they were found

1. A trial build (not kept) with the analysers « unused private member » (IDE0051, IDE0052), « unused field » (CS0169, CS0414, CA1823) and « internal
   class never instantiated » (CA1812) raised to warnings, built into a scratch folder so the game did not reload the plugin.
2. A script listing members whose name appears once in src and tests, and every key of en.json that no code asks for (literal keys, keys built from a
   prefix, keys a helper completes with « Help » or « Tip »).
3. A second check by four agents told to prove each candidate still used (concatenated keys, helpers, tests reading source text, reflection, JSON
   attributes, git history). 94 candidates: 3 still used, 91 unused.

## Kept (still used)

- `GatheringScheduleJsonConverter`: named by `[JsonConverter(typeof(...))]` on GatheringSchedule, exercised by GatheringCatalogCacheTests.
- `MainWindow.NextAlarmCache`: the value type of a ConditionalWeakTable (`nextAlarms.GetOrCreateValue`).

## Removed

- `MainWindow.HoveredNpcCount`, `MainWindow.DrawHoveredNpcs` and the constant `HoverNpcLines`: the old vendor rows of the item hover, no caller left (the
  hover reads `HoverOffers` since 0.704); only an old test pinned their text (updated). Their keys `HoverUi.Npc`, `HoverUi.NpcMore` went with them.
- `MainWindow.ToolMenu` (no caller), `BaseMaterial` record (never used), `BankInventoryBridge.ReadUnavailable` (constant never read),
  `DutyLootDocument.Provider` (never read), `BlueSpellSources.LowestLevel` (never called), `InternalMessages.AllKeys` (never read).
- 87 language keys in en and fr (and those of them in de and ja): most are the old Character page (`CharacterUi.*`, page replaced by CharacterStats in
  0.341 and 0.430), old home tiles, old hover lines, keys left by 0.891–0.897 (spearfishing panel), and help texts of settings that no longer exist.

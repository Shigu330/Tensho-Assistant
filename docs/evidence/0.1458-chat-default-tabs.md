# 0.1458 : les onglets par défaut du chat du jeu (X-445)

La fenêtre de chat de Tensho reprend les trois onglets par défaut du chat du jeu (Général, Combat, Événement), plus Social (décision de
l'utilisateur du 2026-11-15, DEC-053). Lu avec `tools/XbmProbe` le 2026-11-15, client 7.58 (jeu 2026.11.03.0000.0000) :

```
XbmProbe "<sqpack>" English LogFilter
XbmProbe "<sqpack>" French LogFilter
XbmProbe "<sqpack>" English Addon
XbmProbe "<sqpack>" French Addon
```

Feuille `LogFilter` (278 lignes, 8 colonnes : ligne, type de message, deux filtres, catégorie, ordre, **onglet par défaut**, nom, exemple).
La sixième colonne vaut 1, 2, 4 ou 0 ; ses lignes se rangent comme les trois onglets par défaut du jeu : 54 filtres à 1 (tout le chat
des joueurs, messages système, butin, artisanat, récolte, annonces des PNJ), 97 à 2 (vos combats, ceux de l'équipe, des ennemis engagés,
des PNJ alliés, de vos familiers, et « You defeat … »), 1 à 4 (dialogues des PNJ), 126 à 0 (les combats des autres, de l'alliance, des
ennemis non engagés, la pêche des autres : dans aucun onglet par défaut). Extrait brut :

En français, mêmes lignes et mêmes valeurs (« Dialogues des PNJ » à 4, « Annonces des PNJ » à 1, « Messages système de combat
personnels » à 2). La lecture de cette colonne comme l'onglet par défaut vient de ce rangement ; un essai en jeu la compare aux onglets
du jeu (T-0.1458-1).

Noms des onglets : feuille `Addon`, lignes voisines de « Renommer l'onglet » (659) :

```
662|General      663|Battle      665|Event
662|Général      663|Combat      665|Événement
```

Ce que Tensho en fait (`src/TenshoAssistant/Chat/ChatChannels.cs`, `ChatSettings.cs`) :

- Type 58 (« You defeat … ») va avec les lignes de combat (il était avec les messages système depuis 0.1434) ; type 68 (annonces des PNJ)
  avec les annonces ; type 61 (dialogues des PNJ) seul dans Événement.
- Onglet Combat : les lignes de combat de tout le monde (le type ne dit pas qui frappe : Tensho ne le lit pas) ; le jeu ne montre celles
  des autres dans aucun onglet par défaut.
- Les messages ne sont jamais lus ni comptés : copiés et montrés tels que le jeu les montre.

# 0.1458: the game chat's default tabs (X-445)

Tensho's chat window takes the game's three default log tabs (General, Battle, Event), plus Social (the user's decision of 2026-11-15,
DEC-053). Read with `tools/XbmProbe` on 2026-11-15, client 7.58 (game 2026.11.03.0000.0000); raw rows above.

The `LogFilter` sheet's sixth column is 1, 2, 4 or 0, and its rows fall as the game's three default tabs: 54 filters at 1 (all player
chat, system messages, loot, crafting, gathering, NPC announcements), 97 at 2 (your fights, your party's, engaged enemies', friendly
NPCs', your pets', and « You defeat … »), 1 at 4 (NPC dialogue), 126 at 0 (the fights of others, of the alliance, of unengaged enemies,
others' fishing: in no default tab). The French sheet has the same rows and values. Reading this column as the default tab comes from this
grouping; an in-game test compares it with the game's tabs (T-0.1458-1). Tab names: `Addon` rows 662, 663 and 665 (General, Battle,
Event; Général, Combat, Événement), next to « Rename Tab » (659).

What Tensho does with it: kind 58 goes with the combat lines (with the system messages since 0.1434), kind 68 with the announcements,
kind 61 alone in Event; the Battle tab shows everyone's combat lines (the kind does not say who hits; Tensho does not read it), where the
game shows the others' in no default tab; messages are never read nor counted, only copied and shown as the game shows them.

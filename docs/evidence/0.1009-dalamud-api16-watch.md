## What API 16 brings to Tensho's tools

- **Sheets kept working after minor patches** (#2971): goatcorp generates the sheets from EXDSchema and can fix them when Square Enix
  changes a sheet in a minor patch; with API 15 such a sheet stays refused until the next major patch. Fewer broken pages after a patch
  (X-92: update resilience).
- **Map coordinates** (#3035, #3039): `MapCoordinate` and `WorldCoordinate`, `Level` row to world position (`SheetExtensions`),
  territory offsets (`MapUtil`), corrected map maths. Tensho has its own conversion (`Maps/MapProjection.cs`), proven in game: kept
  (KEEP before REPLACE); Dalamud's becomes a cross-check in a test or a probe.
- **Opening the game map and making links** (`OpenMapWithMapLink` helpers with a place name override, `SeString.CreateMapLink`,
  `CreateItemLink` from a `ReadOnlySeString`): « show on the game map » and chat links of places and items from the map, item and
  vendor pages without building the link by hand.
- **Duty found** (`CfPop` with the `ContentFinderCondition` row, no longer on a task): a reminder or alarm when a duty pops, on the
  framework thread.

Already in API 15, not used yet: the `IChatGui.LogMessage` event gives the `LogMessage` row and its parameters. The garden (0.460,
`Reminders/GardenChatWatcher`) recognises its lines by the text of the rows in the client's language; reading the row number would not
depend on the language. To weigh for the chat parsers (garden, discoveries) before API 16, not needed by it.

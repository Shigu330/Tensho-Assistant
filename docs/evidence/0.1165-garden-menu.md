# Garden: which bed a tending line is about (0.1165, X-179)

## The user's finding (2026-11-12)

« entretien manuel ne met pas à jour les alarmes » : dalamud.log of 2026-11-12 shows Tensho recognising the tending lines (LogMessage 4017)
between 12:21 and 12:22 at Shirogane 2-17, then answering « plusieurs emplacements sont notés ici et le jeu ne dit pas lequel » : the line has

« Potager 1, emplacement 6 » (Mettre de l'engrais, Entretenir, Arracher, Annuler).

## The title in the game's sheets

`tools/XbmProbe` (raw sheet, `PROBE_MACRO=1`), sheet Addon, row 6420, 2026-11-12:

| Client | Row 6420 |
|---|---|
| French | `Potager <num(lnum1)>, emplacement <num(lnum2)>` |
| English | `<ordinal(lnum2)> Bed, <ordinal(lnum1)> Patch` |
| German | `Beet <num(lnum1)>, Furche <num(lnum2)>` |
| Japanese | `畑<num(lnum1)>の畝<num(lnum2)>` |

lnum1 is the patch and lnum2 the bed in every language, as in the planting line (LogMessage 4015, French: « Vous avez planté des
graines dans l'emplacement <num(lnum2)> du potager <num(lnum1)>. »). So the title is read with the row's own numbers, not by word order.

## Rule kept

While the player is in housing, the game's choice windows (`SelectString`, `SelectIconString`) are looked at each frame; a title that reads
as row 6420 is remembered with the place (« zone ward-plot »). The next tending, uprooting or harvest line at the same place within 30 s
is about that bed alone; a bed not noted in the journal is left alone (never another one). Without a title read, the old rule stays (one
bed noted here: that one; several: the player is told, and the page has « Whole patch tended »). The window's name is still to be
confirmed in game: in developer mode, « Garden menu read: window <name>, patch N, bed M. » is written once per opening.

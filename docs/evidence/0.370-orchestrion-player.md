# 0.370 — musique en cours et rouleaux favoris (X-02)

Sondes de métadonnées (2026-11-03) :

- `FFXIVClientStructs.FFXIV.Client.Game.BGMSystem` :
  - `Instance()` ;
  - `StdVector<Scene> Scenes`, chaque `Scene` avec `SceneId`, `BgmId`, `PlayingBgmId`, `PreviousBgmId`, `PlayState` ;
  - `SetBGM(UInt16, UInt32, Byte, Boolean, UInt32, UInt32, UInt32, Byte, Byte, Single)` et `ResetBGM(UInt32)`.
- `Lumina.Excel.Sheets.BGM` : `File` ; `Lumina.Excel.Sheets.OrchestrionPath` : `File` (une ligne par rouleau).

Choix :

- La musique en cours est la première scène dont `PlayingBgmId` n'est pas 0 : l'ordre des scènes par priorité est **à confirmer en jeu**.
- Rouleau = ligne OrchestrionPath dont le fichier est celui de la ligne BGM (sans tenir compte de la casse).
- Changer la musique n'est pas fait : `SetBGM` a dix paramètres sans nom ni documentation, et Tensho ne devine pas.

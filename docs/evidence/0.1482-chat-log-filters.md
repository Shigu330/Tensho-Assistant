# 0.1482 : les filtres de la fenêtre de discussion du jeu (X-484)

La fenêtre de chat de Tensho se filtre comme la fenêtre de discussion du jeu (`src/TenshoAssistant/Chat/ChatFilters.cs`). Deux faits sondés
le 2026-11-16, client 7.58 (jeu 2026.11.03.0000.0000), Dalamud 15.0.4.0.

## Ce que Dalamud 15 donne pour chaque message

`tools/ApiProbe` sur `Dalamud.Game.Chat.IChatMessage` : `LogKind` (XivChatType), `SourceKind` et `TargetKind`
(`Dalamud.Game.Text.XivChatRelationKind`), `Sender`, `Message`, `Timestamp`, `IsHandled`. Valeurs de `XivChatRelationKind` :

```
None 0, LocalPlayer 1, PartyMember 2, AllianceMember 3, OtherPlayer 4, EngagedEnemy 5, UnengagedEnemy 6, FriendlyNpc 7,
PetOrCompanion 8, PetOrCompanionParty 9, PetOrCompanionAlliance 10, PetOrCompanionOther 11
```

Le journal de Dalamud du 2026-11-16 03 h 09 montre un message d'objet utilisé lu en « kind 44 » : `LogKind` ne porte plus le sujet ni la
cible dans ses bits hauts ; ils viennent de `SourceKind` et `TargetKind`.

- `Caster` et `Target` sont des masques de `XivChatRelationKind` : bit `1 << valeur` (2 = vous, 4 = équipiers, 8 = alliance, 16 = autres

## Types que la feuille ne liste pas

- 13 (murmure reçu) : la feuille n'a qu'un filtre « Murmurer » (type 12), dont l'exemple montre les deux sens : Tensho range 13 avec lui.
- 32 (équipe inter-Monde) : rangé avec « Équipe » (type 14).
- Les autres types sans ligne (1, 2, 3, 80 à 94 et tout type nouveau) ne sont couverts par aucun filtre : un onglet les montre seulement avec
  « Autres messages » coché (activé quand l'onglet passe aux filtres du jeu).

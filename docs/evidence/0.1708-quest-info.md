# What the Quests page can show (X-606, 0.1708)

The user's request of 18/11: the Quests page gives little information and does not show the quests on the map; do more with the game data
or the discoveries. Probe: `tools/ShopCurrencyProbe`, block `PROBE_QUESTINFO` (`PROBE_QUESTINFO=1`: the counts and three samples;
`PROBE_QUESTINFO=<id,…>`: those quests), run on 21/11/2026 on the installed client, French sheets (Lumina `Lumina.Excel.Sheets.Quest`).

## Samples

- 65564 « Visite au Bannock »: giver Miounne, New Gridania (map 2, territory 132) X 11.7 Y 13.6; ends with Galfrid; level 4; every class
  and job; Chronicles of the Seventh Umbral Era, main scenario section; A Realm Reborn; quests before 65621, 65659, 65660; after 65737.
- 66754 « Naître de ses cendres »: giver Hamujj Gah, Southern Thanalan (map 23) X 24.0 Y 14.3; ends with the same NPC; level 43; allied
  society 1; quest before 66753, after 66755.
- 68142 « Une faim en queue de poisson » (the cook quest of the map's report, sheet row 68142, the 2606th quest): giver Raulf, Mor Dhona
  (map 25, territory 156) X 22.1 Y 5.0; ends with Raulf; level 65; Culinarian; cook quests; Stormblood; before 68141, after 68143.
  Its steps are elsewhere (Limsa Lominsa, read in the game for the map's report): the giver's place is not where an accepted quest's step is.

## What it means for the page

The sheets give, for almost every quest, the giver's name and place (as map coordinates), the NPC it ends with and the jobs it asks; the
page showed none of them as text. The giver's place is a fixed point (the Level row); an accepted quest's current step is read in the game
(the journal's markers), not in the sheets. Coordinates: 41 / (SizeFactor / 100) × ((position + offset) × SizeFactor / 100 + 1024) / 2048 + 1,
the formula of the plugin's map projection.

# Ce que la page Quêtes peut montrer (X-606, 0.1708)

Demande de l'utilisateur du 18/11 : la page Quêtes donne peu d'informations et ne montre pas les quêtes sur la carte ; faire plus avec les
données du jeu ou les découvertes. Sonde : `tools/ShopCurrencyProbe`, bloc `PROBE_QUESTINFO` (`PROBE_QUESTINFO=1` : les comptes et trois
exemples ; `PROBE_QUESTINFO=<id,…>` : ces quêtes), lancée le 21/11/2026 sur le client installé, feuilles françaises (Lumina
`Lumina.Excel.Sheets.Quest`).

## Comptes (5374 quêtes nommées)

| Champ (feuille → colonne) | Quêtes qui l'ont | Montré par la page (0.1707) |
|---|---|---|
| Donneur (Quest.IssuerStart → ENpcResident.Singular) | 5374 (5265 avec un nom) | non (son numéro en mode développeur seulement) |
| Lieu du donneur (Quest.IssuerLocation → Level : Map, Territory, X, Z) | 5269 | un bouton qui ouvre la carte |
| PNJ de fin de la quête (Quest.TargetEnd → ENpcResident) | 5374 (5326 avec un nom) | non |
| Niveau (Quest.ClassJobLevel) | 5374 | oui |
| Jobs (Quest.ClassJobCategory0 → ClassJobCategory.Name) | 5374 | non |
| Genre (Quest.JournalGenre → JournalCategory → JournalSection) | 5194 | oui (section et genre) |
| Lieu (Quest.PlaceName) | 5374 | oui |
| Extension (Quest.Expansion → ExVersion) | 5374 | lue, pas montrée dans le détail |
| Grande compagnie (Quest.GrandCompany) | 21 | non |
| Peuple allié (Quest.BeastTribe) | 689 | non |
| Quêtes d'avant (Quest.PreviousQuest) | 4474 | oui |
| Quêtes d'après (PreviousQuest lu à l'envers) | 3290 | oui |
| Gils (Quest.GilReward) | 4389 | oui (récompenses) |
| Genre du repère (Quest.EventIconType) | 5374 | non |

## Exemples

- 65564 « Visite au Bannock » : donneur Miounne, Nouvelle Gridania (carte 2, territoire 132) X 11,7 Y 13,6 ; se termine avec Galfrid ;
  niveau 4 ; toutes classes et jobs ; Chroniques de la 7e ère ombrale, section de l'épopée ; A Realm Reborn ; quêtes d'avant 65621, 65659,
  65660 ; d'après 65737 .
- 66754 « Naître de ses cendres » : donneur Hamujj Gah, Thanalan méridional (carte 23) X 24,0 Y 14,3 ; se termine avec le même PNJ ;
  niveau 43 ; peuple allié 1 ; quête d'avant 66753, d'après 66755 .
- 68142 « Une faim en queue de poisson » (la quête de cuisinier du rapport sur la carte, ligne 68142 de la feuille, la 2606e quête) :
  donneur Raulf, Mor Dhona (carte 25, territoire 156) X 22,1 Y 5,0 ; se termine avec Raulf ; niveau 65 ; cuisinier ; quêtes de cuisinier ;
  Stormblood ; d'avant 68141, d'après 68143 . Ses étapes sont ailleurs (Limsa Lominsa, lu en jeu pour le rapport sur la carte) :
  le lieu du donneur n'est pas celui de l'étape d'une quête acceptée.

## Ce que cela veut dire pour la page

Les feuilles donnent, pour presque chaque quête, le nom et le lieu du donneur (en coordonnées de carte), le PNJ de fin et les jobs
demandés ; la page n'en montrait aucun en texte. Le lieu du donneur est un point fixe (la ligne Level) ; l'étape en cours d'une quête
acceptée se lit en jeu (les repères du journal), pas dans les feuilles. Coordonnées : 41 / (SizeFactor / 100) × ((position + décalage) ×
SizeFactor / 100 + 1024) / 2048 + 1, la formule de la projection de carte du plugin.

# 0.205 — Commande texte des alarmes du jeu (TextCommand 229)

Sonde en lecture seule `tools/ShopCurrencyProbe`, mode `PROBE_ALARMCMD=1` (données du jeu, 2026-10-31), extraits :

    ALARMCMD 229 English  command '/alarm' alias ''
    ALARMCMD 229 French   command '/alarm' alias '/alerte'
    ALARMCMD 229 German   command '/alarm' alias '/alarm'
    ALARMCMD 229 Japanese command '/alarm' alias ''

Aide (Description) :
- EN : `/alarm "name" [clock type] [repeat] [time] [reminder] [sound effect] [mute]` ; lt/st/et ; « repeat » ou « rp » ;
  heure 0000-2400 ; rappel 0-60 min ; son 00-05 (`se04`) ; mute = pas de son en mission.
- FR : « hl/hs/hé (lt/st/et) », « rp (repeat) », « es[00-05] (se) », « silencieux (mute) » : les formes anglaises entre parenthèses
  sont acceptées. DE : « oz (lt) », « ez (et) », « ton00 » ; JA : formes anglaises.

FFXIVClientStructs (`AlarmFlag.Repeat`) : répétition « horaire en heure locale/serveur, quotidienne en heure ET ».
Exemple donné par l'utilisateur (2026-10-31) : `/alerte "Alerte" et rp 2308 60 es00 silencieux`.

Tensho envoie `/alarm "<nom ≤ 20 car.>" et rp HHmm <0-60> seNN [mute]` par `UIModule.ProcessChatBoxEntry`, au clic ou avec le réglage,
une commande toutes les 0,5 s, jamais au-delà de 30 alarmes du jeu, et seulement des commandes construites par `GameAlarmCommand`.

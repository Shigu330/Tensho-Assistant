# Escouade de Grande Compagnie : ce que le jeu expose (sonde du 2026-11-02)

Sonde en lecture seule `tools/ApiProbe` sur les métadonnées de FFXIVClientStructs et de Lumina (Dalamud dev), sans exécuter de code du
jeu. Rien n'a été lu en jeu : ce sont les champs disponibles, pas leurs valeurs.

## Mémoire du jeu (FFXIVClientStructs)

- `GcArmyManager` : `Instance()`, `GetMemberCount()`, `GetMember(uint)`, `Data`, `LastMissionCompleteNotificationTimestamp`,
  `LastTrainingCompleteNotificationTimestamp`.
- `GcArmyData` : `Members`, `Progress`, `CurrentExpedition`, `BonusPhysical`, `BonusMental`, `BonusTactical`, `MissionRewardExperience`,
  `MemberCount`.
- `GcArmyMember` : `ClassJob`, `Level`, `Experience`, `Flags`, `EnlistmentTimestamp`, traits (`ActiveTrait`…), maîtrises
  (`MasteryIndependent`, `MasteryOffensive`, `MasteryDefensive`), et pour l'équipement **seulement l'apparence** : `GlamourMainHand` …
  `GlamourFeet` et deux teintures par emplacement.
- `GcArmyMemberFlag` : `OnSquadronMission` = 1, `InTraining` = 2, `ReturnedFromMission` = 4.

## Données du jeu (Lumina)

- `GcArmyEquipPreset` : un objet par emplacement (MainHand, OffHand, Head, Body, Gloves, Legs, Feet), apparence des membres.
- `GcArmyExpedition` : nom, description, paramètres, expérience, sceaux, niveau requis, type ; **aucune durée**.

## Complément : PlayerState (même sonde, après lecture des autres plugins)

- `PlayerState` : `SquadronMissionCompletionTimestamp` (Int32), `SquadronTrainingCompletionTimestamp` (Int32),
  `ActiveGcArmyExpedition` (UInt16), `ActiveGcArmyTraining` (UInt16), `HasNewGcArmyCandidate` (bool).
- Lu ainsi par MogHouse Companion (AGPL, lecture seule) ; Accountant (Ottermandias, Apache-2.0) lisait les mêmes heures de fin
  (MissionEnd, TrainingEnd) dans un conteneur statique trouvé par motif d'octets. Squadronista, SimpleTweaks et XA-Database lisent la
  liste des membres dans `GcArmyManager`. Aucun code repris.
- PlayerState est disponible toute la session : pas besoin d'être à la caserne.

## Conclusions

- L'« équipement » d'un membre d'escouade est une apparence (mirage et teintures) : il ne donne aucune caractéristique. Un planificateur
  d'équipement comme celui de R-11 n'a pas d'objet pour l'escouade.
- `GcArmyManager` n'a pas d'heure de fin, mais `PlayerState` en a deux : fin de la mission et fin de l'entraînement en cours.
  Un rappel « fin de mission / fin d'entraînement d'escouade » est donc possible (DEC-023 : heure lisible trouvée), valeurs à
  vérifier en jeu (unité : horodatage Unix, d'après les plugins qui l'utilisent).

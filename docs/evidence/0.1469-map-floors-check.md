# 0.1469 — Floors of every territory checked against the Level sheet (X-480)

Probe: `PROBE_FLOORS=check` of `tools/ShopCurrencyProbe` (French client sheets, game 2026.11.03, read on 2026-11-16), which links the plugin's
own `src/TenshoAssistant/Maps/MapFloors.cs`: the rule below is the one the plugin runs. For every territory whose `planmap.lgb` holds
`MapRange` boxes naming two maps or more (where 0.1464's `MapFloors.MapOf` applied), it compares each Level placement (its own map known in
the sheet) with the map each rule gives it. Level type 8 is an NPC (the vendors and Triple Triad players the loaders place); type 45 an event
object (bells and chests are event objects).

## What 0.1469 does (`MapFloors.Floors`, then `MapOf`)

A box counts only when its map is the territory's map, or another floor of its frame: the same territory, the same scale and offset (a
coordinate reads the same on both), and its own marker range (both ranges set and different). The smallest kept box holding the placement
gives its map; a placement in no kept box stays on the territory's map, never on none.

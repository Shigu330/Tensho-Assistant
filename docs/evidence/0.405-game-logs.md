# 0.405 — ouvrir les carnets du jeu depuis Tensho

Demande de l'utilisateur (2026-11-03) : ouvrir la recette ou la ressource dans le carnet du jeu, au bon endroit.

Sonde `tools/ApiProbe` (métadonnées seulement, 2026-11-03) :

- `AgentRecipeNote.OpenRecipeByRecipeId(UInt32)`, qui passe par `OpenRecipeByRecipeIdInternal` (dans `MemberFunctionPointers`) ;
  aussi `SearchRecipeByItemId(UInt32, UInt32)` (non utilisée) ;
- `AgentGatheringNote.OpenGatherableByItemId(UInt16)` (dans `MemberFunctionPointers`) ;
- pêche : `AgentFishGuide` existe, mais aucune fonction d'ouverture sur un poisson n'a été trouvée : pas de bouton pour la pêche.

Ces fonctions ouvrent une fenêtre du jeu ; rien n'est envoyé au serveur. Appel sur clic seulement, adresse vérifiée avant.
**À confirmer en jeu** : le carnet s'ouvre bien sur la recette ou l'objet.

# 0.368 — progression des succès (C-15)

Sonde `tools/ApiProbe FFXIVClientStructs.FFXIV.Client.Game.UI.Achievement` (métadonnées seulement, 2026-11-03).

Champs du dernier succès demandé :

- `ProgressAchievementId`, `ProgressCurrent`, `ProgressMax` ;
- `ProgressRequestState`.

Fonctions :

- `RequestAchievementProgress(UInt32)` envoie une requête au serveur ;
- `ReceiveAchievementProgress(UInt32, UInt32, UInt32)` reçoit la réponse.

Règle du projet (GAPS.md, C-15) : la demande au serveur part seulement sur un clic du joueur, jamais automatiquement. Tensho n'appelle
`RequestAchievementProgress` que depuis le bouton « Demander », une fois toutes les 3 secondes au plus, après avoir vérifié son adresse.

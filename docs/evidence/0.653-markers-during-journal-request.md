# Event markers during a journal request (0.653)

Report of the user: a click on a started leve in the journal removes its area from the Tensho map; closing the map and clicking again brings it back. Temporary log line, 2026-11-06, same leve as docs/evidence/0.652-leve-markers.md:

11:36:36 The map key closes the Tensho map left open.
11:36:36 Reading events: 12 markers, leve 1, on maps 697; open type "SharedFate", map 0, selected 0, current 697, active false.

## Reading

The game empties `AgentMap.EventMarkers`, all 12 markers and not only the leve's, as long as its map request has type QuestLog with quest 0. The list comes back when that request ends. Tensho read the empty list and drew nothing.

Tensho now keeps what it read just before, while the request lasts and on the same map.

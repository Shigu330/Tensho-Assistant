# Beast Labyrinth: the game's own icon of a damage type and of a weakness (0.1574, X-551)

User request of 2026-11-17 around 10:20 in the Crucible of the Unbroken (side-by-side capture, kept outside the repository): the Tensho panel
« should be reworked to look more like the game's, without growing too much ». Version 0.1534 gave the panel the width of the game's window
and one row per beast; it left the weakness and damage-type icons out, because no icon had been found in the sheets read then
(`XBMElement` was read as text only).

## What the game shows

The developer probe of the game's windows (`dalamud.log`, 2026-11-18 12:53, texts and values of the windows, read only) gives, for the board
window `XBMStageDetailList` and the enemy sheet `XBMBattleMonsterDetail`, the weakness and the type of damage as one text each, a character
before the word:

- board window, guardian of the 1st board: « ?Perforant ; Faiblesse ; Pas de Seul », « 9Feu ; Faiblesse ; Succube mage du plateau »;
- enemy sheet: « 9Feu ; Faiblesse », « =Foudre ; Type de dégâts », « ?Tranchant ; Type de dégâts »;
- beast book `XBMMonsterBookDetail`: « >Eau ; Attaque auto. ».

The character before the word is an icon of the game's font written in the text itself: `9`, `=`, `>` are the bytes 57, 61, 62 of the
icon numbers 56, 60, 61 as the game's texts encode a small number (the number plus one); the physical ones are above 127 and show as an
unreadable character in the log.

## Where it comes from: the sheet's own text

`PROBE_MACRO=1 tools/XbmProbe "<sqpack>" French XBMElement` (game 2026.11.03), the sheet's single column with its macro codes:

| Row | Text with its macro | Font icon |
|---|---|---|
| 1 | `<icon(56)>Feu` | 56 |
| 2 | `<icon(58)>Vent` | 58 |
| 3 | `<icon(59)>Terre` | 59 |
| 4 | `<icon(60)>Foudre` | 60 |
| 5 | `<icon(57)>Glace` | 57 |
| 6 | `<icon(61)>Eau` | 61 |
| 7 | `<icon(185)>Contondant` | 185 |
| 8 | `<icon(186)>Perforant` | 186 |
| 9 | `<icon(187)>Tranchant` | 187 |

The three log lines agree with it: Feu 56 (byte 57, « 9 »), Foudre 60 (byte 61, « = »), Eau 61 (byte 62, « > »). « Neutre » (an unaspected
magical attack, the beast book's word) is not a row of the sheet and has no icon.

## What Tensho does with it

- `BeastCatalogLoader` reads `XBMElement` with its macro codes; `BeastCatalog.IconOfMacro` takes the number of the icon the text starts
  with; `BeastCatalog.ElementIcons` keeps it by the element's name. Nothing is kept in a table of Tensho's own: a row whose text has no icon
  gives none, and the word alone is shown.
- The panel beside the game's board and the team page draw that icon before the word with Dalamud's text renderer
  (`ImGuiHelpers.SeStringWrapped`, an icon payload of the game's font), for an enemy's weakness, an enemy action's type of damage and a
  beast's automatic attack. In the desktop application (no game font) and after a renderer failure, the word alone is shown.
- Layout of the fight shown, after the game's board window: one block per enemy (icon and name, « Faiblesse » and its icon and word, stars,
  actions), a line between enemies.

Still to be seen in game (the panel only exists beside the game's windows): the icons' size and place on the line, and the panel beside
the game's window.

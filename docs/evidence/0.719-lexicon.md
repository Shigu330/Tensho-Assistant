## Source

The game's sheets, read in French and in English by name, whatever the client's language, row by row: `Item`, `Action`, `Trait`, `Status`, `PlaceName`, `BNpcName`, `ENpcResident`, `Quest`, `ContentFinderCondition`, `Mount`, `Companion`, `Fate`, `ClassJob`, `Achievement`, `Emote`, `Addon`. The same (French, English) pair is kept once per kind.

`Addon`: a text with a macro is left out, since it would show with a hole; so are those over 60 characters, which are sentences.

The sheets' French holds soft hyphens and no-break spaces (`Addon` 13987, read through XIVAPI on 2026-11-07): removed, so that a search and a paste work.

## Limits

Searched in memory, off the frame, after one reading on first opening: the words stay in memory while the plugin is loaded. A row with no word on one side is left out: there is nothing to compare. A client that does not hold both languages would show the page as unreadable.

# Livraisons des Planeurs d'Ehcatl : rien de lisible (sonde du 2026-11-02)

Sonde en lecture seule `tools/ApiProbe` sur les métadonnées de FFXIVClientStructs et de Lumina (Dalamud dev) :

- `--find-struct=Ehcatl`, `--find-excel=Ehcatl` : aucun résultat.
- `PlayerState` : aucun champ de livraison propre aux Planeurs (seuls `DeliveryLevel`, les livraisons du Cristarium et le Livre d'or).
- `--find-struct=Delivery` : `AddonDeliveryItemInfo`, `AgentSatisfactionSupply.DeliveryItemInfo` (commandes spéciales, déjà lues).
- `AgentContentsTimer` (fenêtre « Minuteurs » du jeu) : seulement l'interface d'agent commune, aucune donnée publiée.
- Le Calendrier du jeu lui-même n'affiche qu'un état, sans heure (docs/evidence/0.300-calendar-resets.md).

Conclusion (DEC-023, point 6 : « sonder une heure lisible ; sinon laisser de côté ») : laissé de côté. À reprendre si FFXIVClientStructs
expose un jour ces livraisons.

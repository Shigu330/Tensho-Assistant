# 0.417 — R-15 : aide au harpon (sondes en lecture seule)

## Fenêtre du jeu
ApiProbe (métadonnées de FFXIVClientStructs, rien d'exécuté) :
- `AddonSpearFishing`, attribut `[Addon("SpearFishing")]` ; champ `Fish` : tableau de 3 `FishInfo` (`_fish`, décalage 668).
- `FishInfo` : `Available` (bool), `InverseDirection` (bool), `GuaranteedLarge` (bool), `Size` (`SpearfishSize`), `Speed` (Int16).
- `SpearfishSize` : None = -1, Small = 1, Average = 2, Large = 3.
- (Au passage : `AddonGatheringMasterpiece` a l'attribut `[Addon("GatheringMasterpiece")]`, nom utilisé en 0.409.)

## Hypothèse à confirmer en jeu
La vitesse lue dans la fenêtre du jeu (`FishInfo.Speed`) est prise égale à ces valeurs (GatherBuddy les compare à la même fenêtre).
En mode développeur, le panneau affiche la taille et la vitesse brutes de chaque poisson pour le vérifier pendant les tests en jeu.

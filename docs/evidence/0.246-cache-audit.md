# Audit des caches (R-10, 0.246)

Relevé fait dans le code source le 2026-11-01. « Sources » = durée réglable (Réglages › Caches, `CacheArea.Sources`, 7 jours par défaut).
Toutes les lectures réseau sont bornées en taille (`BoundedHttp`) et en temps (délai d'expiration du client).

| Source | Fichier | Cache disque | Durée | Cadence / garde-fous |
|---|---|---|---|---|
| Garland Tools (sources d'objets, butin de donjon et de monstres) | `Community/GarlandClient.cs`, `Duties/DutyLootService.cs`, `Monsters/MonsterLootService.cs` | `sources` | Sources ; 30 min en mémoire pour le butin | une requête toutes les 3 s au plus (`RequestInterval`), 12 s max |
| Wiki (acquisition d'objet, monstres, panoramas) | `Community/WikiItemAcquisition.cs`, `Monsters/WikiMonsterSources.cs`, `Maps/WikiVistas.cs` | `wiki-items`, `wiki-monsters`, `wiki-vistas` | Sources | une requête à la fois, 3 s d'écart ; panoramas : une seule lecture, nouvel essai seulement sur demande ; monstres : 1 min d'attente après erreur |
| LuminaSupplemental (CSV) | `Community/LuminaSupplemental.cs` | `lumina-supplemental` | Sources | une lecture par session. **Corrigé 0.246** : après un échec, nouvel essai à chaque image ; désormais 5 min d'attente, et l'ancienne copie expirée sert si le réseau échoue |
| GatherBuddy (poissons) | `Community/GatherBuddyFish.cs` | `gatherbuddy-fish` | Sources | ~37 requêtes GitHub par période (liste + fichiers `Data*.cs`). **Corrigé 0.246** : même défaut et même correction que LuminaSupplemental |

| Données du jeu : quêtes | `Quests/QuestReader.Dalamud.cs` | Quests | 5 min (relecture) | relecture forcée au plus 1 fois/min tant qu'une cible de quête est sur la carte (0.243) |

Conclusion : hors les deux sources corrigées, aucun outil ne sollicite une source plus d'une fois toutes les quelques secondes,
et chaque réponse est mise en cache pour la durée indiquée.

## Mise à jour 0.281

  dont le cache disque suit la durée « Sources ».

  lecture connue est affichée et datée. Même repli pour le résumé des prix.

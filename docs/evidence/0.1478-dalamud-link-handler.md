# What Dalamud passes to a link handler (0.1478, X-496 M1)

Question: when the player clicks a link of Dalamud or of a plugin (DalamudLinkPayload) in the game's chat, what does Dalamud pass to the
handler registered for it? Tensho's chat window (X-474, 0.1477) must pass the same.

## Source

- Dalamud, `Dalamud/Game/Gui/ChatGui.cs`, method `HandleLinkClickDetour`, branch `master` of goatcorp/Dalamud, read on 2026-11-16
  (https://github.com/goatcorp/Dalamud/blob/master/Dalamud/Game/Gui/ChatGui.cs). Read only, nothing copied.
- Installed Dalamud (`XIVLauncher/addon/Hooks/dev/Dalamud.dll`, 15.0.4.0), searched on 2026-11-16: the method name
  `HandleLinkClickDetour`, the member `RegisteredLinkHandlers` and the log text `Sending DalamudLink to ` are present (same code path).
- `IChatGui.RegisteredLinkHandlers`: `IReadOnlyDictionary<(string PluginName, uint CommandId), Action<uint, SeString>>` (ApiProbe, 0.1477).

## What the method does

1. It runs only for a link whose type is Dalamud's (`linkData->LinkType + 1` is `EmbeddedInfoType.DalamudLink`); otherwise the game's own handler.
2. It reads the link's payloads from `linkData->Payload`, appending each one, and stops after the link terminator (a Link macro of type
   Terminator): **the terminator is appended before the loop stops**, so it is part of the string.
3. The string is parsed (`SeString.Parse`); its **first payload must be the `DalamudLinkPayload`** (else nothing happens); its plugin and
   command pick the handler, called as `handler(link.CommandId, seStr)`.

So a handler gets: the DalamudLinkPayload, the payloads shown inside the link (colours, texts), and the link terminator.

## What Tensho does (0.1478)

- `ChatReader` keeps, for each DalamudLinkPayload of a message, the message's payloads from that link to its end (the first link terminator
  after it, included; the message's last payload when none), encoded (`SeString.Encode`), in `ChatLink.Data` (`ChatPayloads.LinkLast`).
- A left click parses them back (`SeString.Parse`) and calls the handler with them, on the game's thread, as Dalamud does.
- A link copied before 0.1478 (no data) still gets its text, as in 0.1477.
- A handler that throws: the error goes to Dalamud's log (Warning) and the link's tooltip says the plugin could not open it.

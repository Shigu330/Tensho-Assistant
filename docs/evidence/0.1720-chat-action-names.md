# 0.1720: an action's name in a combat line, for its tooltip in the Tensho chat window (X-473)

English first, then French.

## English

### What the game sends (developer mode, 21/11)

Since 0.1715 the developer mode writes the pieces of the combat lines without a link (« pieces of a combat line », one per kind, thirty per
session; kinds and lengths, never the words). Read in dalamud.log on 21/11 between 12:02 and 13:11 (kinds 41 to 45 and 58; T-0.1715-2):

- No line holds a link of the game for an action (no action payload; Dalamud 15's payload types have none either, read in 0.1715).
- An action's name, when the line names one, is a coloured text: `UIForegroundPayload` (a colour on), `UIGlowPayload`, the text,
  `UIGlowPayload`, `UIForegroundPayload` (the colour off); for example kind 44: `PlayerPayload, TextPayload (16 characters), LinkEnd,
  TextPayload (12 characters), UIForegroundPayload, UIGlowPayload, TextPayload (23 characters), UIGlowPayload, UIForegroundPayload,
  TextPayload (1 characters)`. Other lines write the action in their plain text, sometimes after an icon of the game's font: those are left
  as they are.
- A status the game links (`StatusPayload`) colours its own text inside its link: that colouring is not an action.

### What Tensho does (0.1720)

- The reader tells a colour on (its key) from a colour off (`UIForegroundPayload.ColorKey`, 0 off). In a combat line, outside a link, a
  coloured text alone (texts and the game's glow between the colour on and off, with a letter) becomes the name of an action; it is drawn as
  the message's text, nothing to click; the chat history keeps it as text.
- On hover, its tooltip shows the action's icon, name and description (Action and ActionTransient sheets, the client's language), only
  when the name is one action for sure: in a line whose subject is a player (you, your party, your alliance, another player), the player's
  actions of that name (not PvP); else, or when there is none, every action of that name; one row, or rows that all show the same icon and
  description. Rows of that name that differ (an enemy's action named like a player's, for example): no tooltip (never a false one).
- The table of names is made once, at the first hover, on a thread of its own; no tooltip until it is ready.

# 0.1720 : le nom d'une action dans une ligne de combat, pour son info-bulle dans la fenêtre de chat de Tensho (X-473)

L'anglais d'abord, puis le français.

## Français

### Ce que le jeu envoie (mode développeur, 21/11)

Depuis 0.1715, le mode développeur écrit les morceaux des lignes de combat sans lien (« pieces of a combat line », une par genre, trente par
session ; genres et longueurs, jamais les mots). Lu dans dalamud.log le 21/11 entre 12 h 02 et 13 h 11 (genres 41 à 45 et 58 ; T-0.1715-2) :

- Aucune ligne n'a de lien du jeu pour une action (aucun morceau d'action ; les types de morceaux de Dalamud 15 n'en ont pas non plus, lu en
  0.1715).
- Le nom d'une action, quand la ligne en nomme une, est un texte coloré : `UIForegroundPayload` (une couleur mise), `UIGlowPayload`, le
  texte, `UIGlowPayload`, `UIForegroundPayload` (la couleur ôtée) ; par exemple le genre 44 : `PlayerPayload, TextPayload (16 characters),
  LinkEnd, TextPayload (12 characters), UIForegroundPayload, UIGlowPayload, TextPayload (23 characters), UIGlowPayload,
  UIForegroundPayload, TextPayload (1 characters)`. D'autres lignes écrivent l'action dans leur texte simple, parfois après une icône de la
  police du jeu : elles restent telles quelles.
- Un statut que le jeu lie (`StatusPayload`) colore son propre texte dans son lien : cette couleur n'est pas une action.

### Ce que fait Tensho (0.1720)

- Le lecteur distingue une couleur mise (sa clé) d'une couleur ôtée (`UIForegroundPayload.ColorKey`, 0 ôtée). Dans une ligne de combat,
  hors d'un lien, un texte coloré seul (des textes et la lueur du jeu entre la couleur mise et ôtée, avec une lettre) devient le nom d'une
  action ; il est dessiné comme le texte du message, rien à cliquer ; l'historique du chat le garde comme texte.
- Au survol, son info-bulle montre l'icône, le nom et la description de l'action (feuilles Action et ActionTransient, langue du client),
  seulement quand le nom désigne une seule action à coup sûr : dans une ligne dont le sujet est un joueur (vous, votre équipe, votre
  alliance, un autre joueur), les actions des joueurs de ce nom (hors JcJ) ; sinon, ou s'il n'y en a pas, toutes les actions de ce nom ;
  une ligne de la feuille, ou des lignes qui montrent toutes la même icône et la même description. Des lignes de ce nom qui diffèrent (une
  action d'ennemi qui porte le nom d'une action de joueur, par exemple) : pas d'info-bulle (jamais une fausse).
- La table des noms est faite une fois, au premier survol, sur un fil à part ; pas d'info-bulle tant qu'elle n'est pas prête.

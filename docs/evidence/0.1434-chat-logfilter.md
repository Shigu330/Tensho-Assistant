# 0.1434 : les types de message du chat groupés comme les filtres du jeu (X-403, phase 1)

La fenêtre de chat de Tensho (D-166) range chaque type de message du jeu (`XivChatType` de Dalamud, API 15) dans un canal
(`src/TenshoAssistant/Chat/ChatChannels.cs`). Trois types changent de canal par rapport à la 0.471, d'après la feuille `LogFilter` du jeu
(les filtres de la fenêtre de chat du jeu), lue avec `tools/XbmProbe` le 2026-11-15, client 7.58 (jeu 2026.11.03.0000.0000) :

```
XbmProbe "<sqpack>" English LogFilter
```

Colonnes : ligne, type de message, deux filtres, catégorie, ordre, drapeau, nom du filtre, exemple. Extrait brut :

```
21|57|65535|65535|2|1|1|System Messages|You invite Cloud Strife to a party.
24|60|65535|65535|2|5|1|Error Messages|Message to Cloud Strife could not be sent.
37|58|1807|65535|2|2|2|Own Battle System Messages|You defeat the Shadow Lord.
38|58|2193|65535|2|3|0|Others' Battle System Messages|Cloud Strife defeats the little ladybug.
45|73|65535|65535|2|46|1|Sign Messages for PC Targets|You mark Cloud Strife as "Target to Ignore 1."
46|74|65535|65535|2|47|1|Random Number Messages|Random! You roll a 998.
```

- Type 58 : messages système de combat (« You defeat … »), pas des erreurs (60) : canal Système.
- Types 73 (marques sur une cible) et 74 (`/random`) : messages système : canal Système, plus « Autre ».
- Les noms et préfixes français des canaux viennent de la même feuille en français.

# 0.1434: the chat's message kinds grouped as the game's filters group them (X-403, phase 1)

The Tensho chat window files each game message kind (Dalamud's `XivChatType`, API 15) into a channel (`Chat/ChatChannels.cs`). Three kinds
move from their 0.471 channel, from the game's `LogFilter` sheet (read with `tools/XbmProbe`, 2026-11-15, client 7.58; raw rows above):
58 is « Own/Others' Battle System Messages » (« You defeat … »), not an error (60): System; 73 (sign messages) and 74 (random numbers):
System instead of Other.

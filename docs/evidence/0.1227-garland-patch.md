# 0.1227 — Garland Tools: the patch that added an item (X-224)

Read on 2026-11-13 from the public item documents that Tensho already downloads for the item sources
(`https://www.garlandtools.org/db/doc/item/<lang>/3/<id>.json`, same route as `Community/GarlandClient.cs`), field `item.patch`:

| Item | Language | `item.name` | `item.patch` | `item.patchCategory` |
|---|---|---|---|---|
| 5057 | en | Iron Ingot | 1.0 | 5 |
| 43557 | fr | Vieille carte en peau de br'aax | 7.0 | 5 |
| 46246 | fr | Sable éthéréen de la foudre violette | 7.3 | 5 |

`patch` is a JSON number (major.minor of the patch). Tensho keeps it only from 1.0 to 20.0, rounded to the hundredth
(`GarlandItemSourceParser.PatchOf`), and shows it in the item sheet's header when the document is already read; nothing is shown when the
field is absent or not plausible. `patchCategory` is not used.

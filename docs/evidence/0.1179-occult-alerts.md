# 0.1179 — Occult Crescent critical engagements and FATEs (X-189)

Sources: the members of FFXIVClientStructs read with `tools/ApiProbe` (Dalamud 15.0.4.0, game version 2026.11.03.0000.0000).

## What the game holds

- `DynamicEventContainer` (`GetInstance()`, 7 552 bytes): `Events` (16 `DynamicEvent`), `CurrentEventId`, `CurrentEventIndex`.
- `DynamicEvent` (464 bytes): `DynamicEventId`, `DynamicEventType`, `EventType`, `State` (`DynamicEventState`: 0 Inactive, 1 Register,
  2 Warmup, 3 Battle), `StartTimestamp`, `SecondsLeft`, `SecondsDuration`, `Participants`, `MaxParticipants`, `Progress`, `LGBMapRange`,
  `Name`, `Description`, `MapMarker` (`MapMarkerData`: `MapId`, `Position`, `Radius`, `IconId`, `EndTimestamp`, `EventState`).
- FATEs come from Dalamud's `IFateTable`, already read by the map (`MapLiveReader`, `MapFateMarker`).

## What Tensho does with it

- The reader of 0.1176 copies, once a second while the island's director exists, the engagements that are not inactive (id, name, state,
  seconds left, start, map and position of the marker).
- An engagement in state Register (the game's « New critical engagement! Starts in 1:07 ») is said once in the chat and to the desktop
  application, with the time left and the marker's place; a FATE of the island once when it appears. DEC-041: nothing during a fight; what
  opened then is said once the fight is over, if still open.
- Developer mode writes the container (`Reading occultevents`) when an engagement appears, changes state or progress, or goes, to check the
  meaning of `SecondsLeft` in each state (time to the start in Register is assumed from the game's message, not yet seen in a reading).

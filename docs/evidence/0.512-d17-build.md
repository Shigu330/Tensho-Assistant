# Comment le dépôt Dalamud compile un plugin (relevé du 2026-11-04)

Lu pour vérifier que Tensho se compile chez eux. Sources, branche `master` de goatcorp/Plogon, lues le 2026-11-04 :
`Plogon/BuildProcessor.cs`, `Plogon/static/entrypoint.sh`, `global.json` ; README de goatcorp/DalamudPluginsD17.

## Ce que fait la compilation

- Conteneur Linux, image `mcr.microsoft.com/dotnet/sdk:10.0.101` (constante `DockerTag`), réseau coupé (`NetworkDisabled = true`).
- Commande, depuis `/work/repo/<project_path>` :
  `dotnet build -c Release -o /output -p:DalamudLibPath=/work/dalamud/ -p:IsPlogonBuild=True`.
- Paquets : lus dans chaque `packages.lock.json` du dépôt (erreur s'il n'y en a aucun), puis copiés dans un dossier local. Un seul
  paquet d'outillage forcé : `Dalamud.NET.Sdk` 15.0.0. Chaque dépendance NuGet est examinée par l'équipe (« need »).
- Refus : une DLL interne de Dalamud dans la sortie (`Dalamud.dll`, `ImGuiScene.dll`, bindings) ; une référence
  `Dalamud.NET.Sdk` mal capitalisée dans le csproj ; un manifeste produit absent ou dont le nom interne ne correspond pas.

## Conséquences pour Tensho

- **Blocage corrigé en 0.512** : `global.json` demandait 10.0.403 avec `latestPatch`, donc aucun SDK de leur image ne convenait.
  Il accepte maintenant 10.0.100 et plus (`latestFeature`). `Verify.ps1` prend le SDK 10.x installé le plus récent sous `.codex`.
- Tensho n'avait jamais été compilé sous Linux : un job de `build.yml` (0.512) reprend leur image, leur commande et un
  `dotnet restore --locked-mode`, et contrôle la sortie. Il tourne avec le réseau, pour télécharger Dalamud et les paquets : il ne
  reproduit pas le réseau coupé.
- `Raphael.Net` 5.0.0 (MIT, bibliothèque native incluse) : même version que Craftimizer, déjà publié sur leur dépôt
  ([étude](0.451-raphael-study.md)). L'équipe l'examinera comme toute dépendance.
- Dalamud stable relevé le même jour : 15.0.3.9, runtime 10.0.14 (`kamori.goats.dev/Dalamud/Release/VersionInfo`) ;
  `Dalamud.NET.Sdk` 15.0.0 est la dernière version sur NuGet.

## Ce que l'équipe vérifie (README de DalamudPluginsD17 et page d'approbation)

Règles respectées ; éléments de combat seulement informatifs, limités à ce que le joueur saurait déjà ; relecture informelle du code ;
installation propre ; fenêtre de configuration correcte ; fonctions de base ; JSON correct ; canal de test pour un nouveau plugin ;
aucune donnée personnelle envoyée ; code ouvert. Quatre votes favorables, un veto suffit à refuser.
La file peut dépasser une semaine (bénévoles).

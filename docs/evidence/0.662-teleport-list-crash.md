# Game crash in the teleport list (0.662)

`%AppData%/XIVLauncher/dalamud_appcrash_20261106_130007_337_39948.log`, game crash reported by the user on 2026-11-06:

```
Unhandled native exception occurred at ffxiv_dx11.exe+C1C5D8 (Client::Game::UI::Telepo.UpdateAetheryteList+0xA8)
Code: C0000005
[0] ffxiv_dx11.exe+C1C5D8 (Client::Game::UI::Telepo.UpdateAetheryteList+0xA8)
[1] TenshoAssistant.Maps.MapLiveReader.ReadTeleportCosts()
[2] TenshoAssistant.Maps.MapLiveReader.Update(Dalamud.Plugin.Services.IFramework)
RBX: 0, RCX: 0
```

## Cause

Tensho's own call. `MapLiveReader.Update` served the teleport list request before checking for a player. Before 0.645 a request came only from a click. Since 0.645 (P7), `DrawMapCanvas` asks for it whenever the shown map or the player's map changes, so also during a change of zone. Between 0.645 and this version, a zone change with the Tensho map open could crash the game.

## Change

The request waits, and the function is called only with a player loaded, out of a change of zone, for 3 seconds.

## Not established

- What exactly is null at +0xA8: RCX is 0, the code of the function was not read. That no player was there at that moment is inferred: the call order allowed it, and the user was changing zones. The log stops at 12:57, before the crash.
- 3 seconds is a margin, not a measure.

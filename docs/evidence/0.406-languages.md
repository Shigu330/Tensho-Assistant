# 0.406 — langues : audit et règle

Demande de l'utilisateur (2026-11-03) : objets du jeu (et pas que les objets) dans la langue du jeu, textes traduits dans la langue du
plugin (anglais = original), mode développeur et journal couverts, journal en anglais ; « mettre en place ce qu'il faut pour continuer ».

Audit du code (scripts en lecture seule) :

- 178 lectures de feuilles du jeu, toutes dans la langue du client ; l'anglais n'est demandé que pour rapprocher des sources
  extérieures (wiki, Garland, météos), lire des noms de colonnes techniques (abréviations des jobs) ou nommer une page du wiki.
- 210 messages du journal, tous en anglais.
- 200 textes français accentués et 76 sans accent dans le code (messages, erreurs, états). 197 + 57 traduits en anglais ; gardés en
  français : noms des cristaux du client français (lus), noms des fêtes (client français), alias de commande « pêche ».
- 24 + 6 affichages bruts du mode développeur.

Mise en place :

- UI/InternalMessages.cs : 147 messages anglais → clé de traduction ; textes français d'origine et anglais dans les fichiers de langue ;
  les tables existantes (UiMessages, CraftMessages) s'y reportent.
- Mode développeur : les messages bruts passent par la traduction (RawMessage) ; libellés techniques en clés DevMode.
- Test Languages406Tests : aucun texte français dans le code hors fichiers de langue et exceptions listées ; chaque clé a ses deux textes.
- Règle écrite dans notes de l'agent.

Reste à faire (proposé à l'utilisateur) : noms de monstres et lieux venus du wiki ou de Garland (anglais) affichés dans la langue du jeu.

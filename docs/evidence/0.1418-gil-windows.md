# 0.1418: gil reward windows (X-18)

Question: which game windows pay gil, beyond those of 0.351 to 0.1319, so that fewer gains stay « Other » in the gil journal?

## Probe

`tools/UldProbe` on the client 7.58 (2026-11-15): the layout file of each window name.

| Window | Layout | What it is |
|---|---|---|
| `JournalResult` | `ui/uld/JournalResult.uld` present | the journal's reward window (a quest or a leve handed in: its rewards, gil among them) |
| `SatisfactionSupply` | `ui/uld/SatisfactionSupply.uld` present | the custom deliveries' window (a delivery pays gil) |
| `XBMResult` | `ui/uld/XBMResult.uld` present | the Beastmaster trial's result; seen in dalamud.log on 2026-11-13: « Gil other: +2,000, windows seen in the last 15 s: XBMResult, NeedGreed, NowLoading, XBMContentsMainHUD » ([0.1319](0.1319-gil-other.md)) |

## Rule (GilJournal, 0.1418)

A gain while one of these windows was seen in the last 15 seconds: « Quests and leves (rewards) », « Custom Deliveries », « Beastmaster
(trial results) ». A spending next to them stays « Other ». The newest window seen wins, as for the others. Entries already written keep
their category. Still to see in the game: a quest handed in, a custom delivery made and a trial finished each give their gain the category.

# 0.1418 : fenêtres qui versent des gils (X-18)

Sonde `tools/UldProbe` (client 7.58, 15/11/2026) : `JournalResult` (récompenses du journal : quête ou mandat rendu), `SatisfactionSupply`
(commandes spéciales) et `XBMResult` (résultat d'un plateau du Dédale, vu au journal le 13/11 avec +2 000 resté « Autre ») existent dans le
client. Un gain pendant que l'une d'elles a été vue dans les 15 dernières secondes prend sa catégorie ; une dépense reste « Autre » ; les
entrées déjà écrites gardent la leur. Reste à voir en jeu : une quête rendue, une commande spéciale livrée, un plateau fini.

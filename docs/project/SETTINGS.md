# Tensho Assistant settings

> *Traduction française plus bas.*

Inventory produced by `tools/docgen.py` (system plan 4.16), read from the code at every version: every settings control drawn by the
shared components (`BoolSetting`, `IntSetting`, `SliderSetting`, `ComboSetting`, the map's `SettingBox`), the `Configuration` property
it writes, its type and its default value (initializer of the property or of its field), where to find it (tab of Settings according to
`SettingsIndex`, otherwise the page) and its texts (label and tooltip from the language files; English here, French in the French half).
A row marked `(key)` is a control that does not write directly into `Configuration` (font, shared switch of the sources, macros).
The second table lists the settings reset by « Restore every setting » (`ConfigurationReset.Reset`) that none of these controls writes.

Do not write in the block by hand: `python -I -X utf8 tools/docgen.py write`. The inventory made by hand in 0.943 and 0.971 (real
effect, what changes when it is turned off, where the code reads it, the nine defects fixed in 0.944) is kept, in French, in
[archive/SETTINGS-INVENTAIRE-0.971.md](https://github.com/Shigu330/Tensho-Assistant/blob/024c426c1186a2e8f51e09087996a9c55208c28a/docs/project/archive/SETTINGS-INVENTAIRE-0.971.md); its line numbers date from 0.943.

# Réglages de Tensho Assistant

Inventaire produit par `tools/docgen.py` (plan système 4.16), tiré du code à chaque version : chaque case de réglage dessinée par les
composants communs (`BoolSetting`, `IntSetting`, `SliderSetting`, `ComboSetting`, `SettingBox` de la carte), la propriété de
`Configuration` qu'elle écrit, son type et sa valeur par défaut (initialiseur de la propriété ou de son champ), où la trouver (onglet de
Paramètres d'après `SettingsIndex`, sinon la page) et ses textes (libellé et info-bulle des fichiers de langue ; en français ici, en
anglais dans la moitié anglaise).
Une ligne marquée `(clé)` est une case qui n'écrit pas directement dans `Configuration` (police, interrupteur commun des sources, macros).
Le deuxième tableau liste les réglages remis par « Tout remettre par défaut » (`ConfigurationReset.Reset`) qu'aucune de ces cases n'écrit.

Ne pas écrire dans le bloc à la main : `python -I -X utf8 tools/docgen.py write`. L'inventaire fait à la main en 0.943 et 0.971 (effet
réel, ce qui change quand on coupe, où le code le lit, les neuf anomalies corrigées en 0.944) est gardé dans
[archive/SETTINGS-INVENTAIRE-0.971.md](https://github.com/Shigu330/Tensho-Assistant/blob/024c426c1186a2e8f51e09087996a9c55208c28a/docs/project/archive/SETTINGS-INVENTAIRE-0.971.md) ; ses numéros de ligne datent de 0.943.

## Méthode

- **Règles de publication Dalamud** relevées sur dalamud.dev (restrictions, submission, approval-process, technical-considerations,
  ai-policy, actualités Account ID) et le README de goatcorp/DalamudPluginsD17 : 19 pages.
- **Dépôt officiel** : liste complète kamori.goats.dev/Plugin/PluginMaster (500 plugins), recoupée avec les
  dossiers stable/ et testing/live/ de D17 ; 177 plugins touchent un domaine d'aide non combat de Tensho.
- **Dépôts non officiels** : agrégateur NexusFFXIV/DalamudRepo (554 dépôts tiers), Sea of Stars, puni.sh, NightmareXIV, Paissa ;
  658 plugins vus, 76 gardés en tout ou en partie, jugés règle par règle (absence de D17 ≠ violation).
- **Comparaison** : un agent par domaine de Tensho ; chaque fonction comparée est cherchée dans le code (`src/TenshoAssistant/`), la
  documentation seule ne compte pas comme preuve. Licence lue dans le fichier LICENSE de chaque dépôt (environ 250 dépôts).
- **Contre-vérification** adverse : licences, règles, sources de données (sondes `tools/ApiProbe`), et 30 affirmations de couverture
  relues dans le code (20 corrigées : statut, preuve ou numéro de ligne). Les corrections sont reportées ci-dessous (colonne « Note »).
- Hors périmètre gardé : combat, ACT/IINACT, JcJ (DEC-009), et toute automatisation du jeu (règles Dalamud). Exception ajoutée depuis : dresseur, informations seulement, JcE seulement (DEC-032).

## Règles qui encadrent chaque ajout

- **Interdit** : interaction automatique avec les serveurs du jeu (requête ou interrogation sans action directe du joueur),
  artisanat automatisé, saut de dialogues ou de cinématiques, jet de butin automatique ; tout avantage en combat ou en JcJ ; parsers ;
  accès aux objets de la boutique en ligne ; collecte des Account ID d'autres joueurs ; dépendance obligatoire à un plugin non conforme.
- **Données que le jeu n'envoie qu'à l'ouverture d'une fenêtre** (marché des servants, coffre de compagnie, coffre à apparence,
  progression des succès, minuteurs des ventures) : lues seulement après une ouverture faite par le joueur. Tensho n'appelle aujourd'hui
  aucune fonction qui déclencherait ces requêtes (`RequestAchievementProgress`, `RequestVenturesTimers`, `SetRetainerMarketPrice`…).
- **Envoi vers un service** (Universalis, Discord de R-12…) : choisi par le joueur, minimum de données, HTTPS ; aucune donnée
  personnelle sans accord. Les services tiers ne sont pas traités explicitement par les règles : revue au cas par cas.
- **Zone grise** : ce qui agit d'office (alarme du jeu par `/alarm`, tri automatique) reste désactivé par défaut et se justifie dans la PR.

  enchaînés), Questionable, YesAlready, TextAdvance, Saucy, LazyLoot, AutoHook, Pandora's Box, Gardener (entretien de toutes les
  parcelles), Chocobo Colourized (nourrissage automatique), InventoryCleaner (déplacements en série), Stylist (mise à jour de tous les
  ensembles), HuntTrainAssistant (drapeaux et téléportation automatiques ; ses parties sans automatisme restent lisibles).
- Dépôt dajoey/lalalazy (LazyCrafter, Armoire Auto-Fill, Lazy Skyward Tracker, Lazy Gear Collector) : sans licence, et le même dépôt
  publie de l'automatisation et un solveur JcJ ; idées seulement, aucun code ni IPC.
- Envois de données actifs par défaut (statistiques de WTSync, envoi de LangSwap) : contraires à la règle du projet, non repris.
- Combat, JcJ, parsers : hors périmètre (DEC-009).

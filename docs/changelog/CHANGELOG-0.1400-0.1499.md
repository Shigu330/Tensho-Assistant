## 0.1426.0
- Mesure pour X-433, cinquième étape. La 0.1425 a lié l'à-coup à l'échauffement du code : QuestReader 364 ms en une image (16 ms de processeur) a fini à 15 h 38 min 58,417 s, la milliseconde même où l'échauffement finissait de compiler MainWindow.DrawDiscoveryPlaces (682 ms) ; une suspension de tous les fils de 728 ms (35,882 s) a fini avec la compilation de 730 ms d'une lambda de DrawMapOverlayControls (36,611 s). Ces méthodes sont courtes (56 et 93 lignes). Soit le fil d'échauffement, de priorité basse, est préempté pendant qu'il tient ce dont le fil du jeu a besoin (inversion de priorité), soit la compilation travaille vraiment aussi longtemps. Les compilations les plus longues de l'échauffement disent maintenant le temps processeur de son fil (mode développeur).
- Tests : WarmupProcessor1426Tests. Verify.ps1 (agent) : 2716/2716, 0 avertissement, 0 erreur ; DLL 0.1426.0.0. Rien à essayer en jeu.
### English
- Measure for X-433, fifth step. 0.1425 tied the hitch to the code warm-up: QuestReader 364 ms in one frame (16 ms on the processor) ended at 15:38:58.417, the very millisecond the warm-up ended compiling MainWindow.DrawDiscoveryPlaces (682 ms); a 728 ms suspension of every thread (35.882) ended with the warm-up's 730 ms compilation of a lambda of DrawMapOverlayControls (36.611). Those methods are short (56 and 93 lines). Either the below-normal warm-up thread is preempted while it holds what the game's thread needs (a priority inversion), or the compilation really works that long. The warm-up's longest compilations now say its thread's processor time (developer mode).

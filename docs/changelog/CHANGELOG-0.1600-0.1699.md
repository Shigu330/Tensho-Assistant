M1: the message « sent without the refused copy » (ShareAsideGivenUp) was said only when the send right after the give-up ended in « Sent »; when that send failed (network, 5xx), the rows were already settled and the next exchange said « Sent » only: the player never learnt those discoveries left the gist.

## 0.1663.0
- Plan global, X-687 : Fenêtre de chat (X-687, demande de l'utilisateur du 20/11 vers 22 h 05 : « aucun moyen de ranger les onglets »). Les onglets se rangent : en les faisant glisser à la souris dans la fenêtre (barre d'onglets ImGui avec le drapeau Reorderable ; chaque onglet porte un identifiant propre, plus sa place ; l'ordre montré par la barre est relu à la fin du glissement et devient celui des réglages, l'onglet affiché gardé), par « Déplacer à gauche » et « Déplacer à droite » dans le menu du clic droit d'un onglet, et par les mêmes boutons dans les réglages de chaque onglet (pour qui ne peut pas glisser, et quand les noms des onglets sont cachés). L'ordre est celui de ChatSettings.Tabs, enregistré, donc gardé au rechargement. Les onglets de conversation (en mémoire) restent après ceux des réglages : glissés avant, ils reviennent à leur place. Profils par contexte : un seul ordre pour la fenêtre et ses profils (choix appliqué, D-200) ; dans un profil qui ne montre qu'une partie des onglets, ceux-ci échangent leurs places entre eux, les autres gardent la leur. Hors glissement, la barre montre toujours l'ordre de la liste (refaite dans cet ordre si besoin, l'onglet affiché sélectionné).
- Pour les joueurs : fenêtre de chat : les onglets se rangent, à la souris ou par leur menu et leurs réglages ; l'ordre est gardé.
- Tests : ChatTabOrder1663Tests. Verify.ps1 (agent) : 3498/3498, 0 avertissement, 0 erreur ; DLL 0.1663.0.0. Non validé en jeu.
### English
- Chat window (X-687, the user's request of 20/11 around 22:05: « no way to sort the tabs »). The tabs can be put in order: dragged with the mouse in the window (ImGui tab bar with the Reorderable flag; each tab has an id of its own, no longer its place; the order the bar shows is read when the drag ends and becomes the settings' order, the tab shown kept), by « Move left » and « Move right » in a tab's right-click menu, and by the same buttons in each tab's settings (for whoever cannot drag, and when the tabs' names are hidden). The order is ChatSettings.Tabs', saved, so kept at reload. The conversations' tabs (in memory) stay after the settings' ones: dragged before them, they go back to their place. Context profiles: one order for the window and its profiles (choice applied, D-200); in a profile showing some of the tabs only, those swap their places among themselves, the others keep theirs. Outside a drag, the bar always shows the list's order (made again in that order when needed, the tab shown selected).
- For players: Chat window: the tabs can be put in order, dragged with the mouse or moved by their menu and settings; the order is kept.
